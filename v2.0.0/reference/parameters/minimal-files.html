Minimal files#

For each section, the smallest file that holds it: the sections every file needs, then the keys the section requires, each with its example value or its default. Each file below passed HydroModPyConfig when this page was built. hmp config template --modules <section> writes every key of a section, commented, and hmp check file.toml validates what you wrote.

[edition]

This key is one line of the file, so it has no template.

hmp config template --modules workflow > workflow.toml
