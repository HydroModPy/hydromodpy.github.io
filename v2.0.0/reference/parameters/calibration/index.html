[calibration]#

Top-level [calibration] section.

  • calibration [table] · optional · 116 user keys, 5 dev or expert
  • Start a file: hmp config template --modules calibration (download it), then hmp check file.toml. Minimal file
[calibration]
# method = ‹string›Optimization method. experimental
Path
calibration.method
More

Unset, it follows from what the calibration scores: 'bisection' when it moves one parameter in log space and every one of its blocks is signed (distance_gap), since the answer is then a zero to find; 'scipy_nelder_mead' otherwise, a cost to minimise. Write it to depart from that choice, and whenever method_options are given. A phase of [[calibration.phases]] names its own. Built-ins: 'grid' (regular sweep, sized by method_options.points_per_dim), 'lhs' (stratified Latin hypercube, sized by method_options.n_samples), 'random_search', 'bisection' (root of a signed criterion on one parameter, the stream-network stage), 'optuna' (TPE), 'cma_es', 'scipy_de', 'scipy_nelder_mead' and 'gp_mapping'. An unknown name is refused when the file is read, with the list installed here. Optuna is installed by default; install the calibration extra for cma_es and Optuna's cmaes sampler.

Accepted
string
# evaluator = ‹string›What turns one parameter sample into a cost. experimental
Path
calibration.evaluator
More

Unset runs the HydroModPy pipeline, which is what every calibrated number in this repository was produced with. A string and not an enumeration: the values that resolve depend on what is installed beside HydroModPy, which is how a surrogate or a foreign model is named without a patch. This build also ships 'analytic_bowl', which runs no model and scores a closed-form surface whose minimum is the midpoint of each parameter's interval: it rehearses a whole search -- space, optimizer, stopping rule, report -- in milliseconds, against an answer known in advance.

Accepted
string
# max_trials = "auto"Maximum number of evaluations of the search. > 0 experimental
Path
calibration.max_trials
More

It is the only bound on how long a search runs: no method option counts evaluations of its own. 'auto' lets an engine that counts its evaluations before the first solve size its own budget. Three do. The grid and the Latin hypercube count their design, one evaluation per point, and refuse a smaller number before the first solve, since a sweep cut short is not its design. The bisection counts with d the declared interval in decades, t = log10(1 + rel_tol), S the sweep points (counted as 2 for sweep_points 0), s = d / (S - 1) and E = bracket_expand, a root inside the bounds costs S + ceil(log2(s / t)) and one found after e expansions S + 2e + ceil(log2(1 / t)); 'auto' budgets the largest, 23 on [1e-7, 1e-3] m/s with seven points and one per cent (15 inside the bounds). A number below the nominal count is refused before the first solve, one below the worst case is announced, and a budget that still runs out gets exactly the halvings left, once. Any other engine gets 100 from 'auto' and no extension: a search that spends its budget before its own stopping rule is reported as not converged, and a re-run with a larger max_trials replays the trials already solved from the cache.

Values
  • "auto"
Accepted
integer or "auto"
Valid range
> 0 (refused outside)

# precision = ‹number›How precisely the search has to pin a parameter before it stops, as a relative precision on the parameter itself: 0.01 asks for one per cent, 0.1 for ten. - > 0 experimental
Path
calibration.precision
More

On a parameter searched in log space that is a ratio, which is how a conductivity is known in the first place, and it holds wherever the value sits; on any other search space there is no scale on the value to be relative to before the search has one, so it reads as a fraction of the declared interval. Each engine's own stopping option is written from it, so the same number survives a change of engine, and the engine's own option stays available for reproducing a published call verbatim. Unset, the engine's default applies. An engine that stops on its budget rather than on a precision refuses this rather than ignore it.

# parallel = 1Trials solved side by side, each in its own folder, for every phase that sets none of its own. - >= 1 experimental
Path
calibration.parallel
More

A grid or a random search evaluates its points together; a root search cuts its bracket into parallel + 1 parts; a simplex evaluates the candidates of one step together and keeps the sequential answer, so a width above 4 buys it nothing, and CMA-ES and differential evolution stop at their population. A width above 1 gives each worker process its own copy of the model (about 0.5 GiB, 3 s to start); 1 solves the trials one after the other in this process.

# reject_water_budget_above = 1.0Percent water-balance discrepancy of the whole model past which a trial is rejected instead of scored. % >= 0 experimental
Path
calibration.reject_water_budget_above
More

The figure is the one the solver prints for the volume budget of the entire model, not the budget of a single package such as the lake package, which divides by small flows and reads higher. A rejected trial is marked failed, so it is neither ranked nor promoted: part of the water it routed came from nowhere and its cost is not comparable to a run that closed. Default 1.0 (one per cent). Raise it for a transient model whose lake or routed network legitimately sits higher. A TOML file has no null: to switch the gate off write a value no run reaches, such as 1000, or pass None from Python. The worst time step of the run decides, not the last.

# objective = "nse"Metric scoring the single simulated series, when no objective block is declared. experimental
Path
calibration.objective
More

Same vocabulary as a block's 'metric'; typed here so a bad value is reported against the key that was written.

Values
  • "rmse" : Root-mean-square error, in the observed unit; penalizes large misfits most.
  • "nse" : Nash-Sutcliffe efficiency against the observed mean; the standard choice for a level or discharge series.
  • "kge" : Kling-Gupta efficiency, 2009 form (bias as the ratio of sums, variability as the ratio of standard deviations); separates correlation, variability and bias when NSE alone is ambiguous.
  • "mae" : Mean absolute error, in the observed unit; less sensitive to outliers than RMSE.
  • "nse_log" : NSE on log-transformed series; weights low flows as heavily as peaks, good for recessions.
  • "nse_delta" : NSE on the increments of the series rather than its level; a level is an integral and can hide flux errors that compensate, which only its increments show.
  • "nse_seasonal" : NSE against the seasonal cycle rather than the overall mean; asks whether the model beats climatology.
  • "reservoir" : Half nse_seasonal plus half nse_delta, built for an impounded level: a plain NSE there is beaten by the seasonal cycle, and the increments are what carry the flux errors.
  • "distance_gap" : Balances the simulated stream network against the mapped one; zero marks the crossing.
  • "distance_mean" : Mean spatial offset between simulated and mapped streams; a diagnostic, not a substitute for distance_gap.
Accepted
"rmse" | "nse" | "kge" | "mae" | "nse_log" | "nse_delta" | "nse_seasonal" | "reservoir" | "distance_gap" | "distance_mean"
