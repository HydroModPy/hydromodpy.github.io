Figure requests#

Every table on this page is read from the code of the figure path when the site is built. To draw one, see Add a figure.

Fields#

A figure is a request, and a request holds panels.

Fields of a figure

FieldTypeDefaultWhat it doesAccepted
presetstr or noneunsetName of a shipped preset or of one of your own presets.hydrograph, residuals, water_budget, watershed_id_card, network_expansion, calibration_landscape, calibration_progress, ensemble_band, flow_directions, lake_abacus_comparison, network_comparison, observed_network_heads, particle_tracks, recession, residence_time_distribution, root_search, sfr_longitudinal_profile
panelslist[PanelRequest] or noneunsetThe panels, in order.
drawfunction or noneunsetPython function that draws the figure, draw(subject, ax, theme). Never written in a file.
namestr or noneunsetFile name of the figure, no suffix.
titlestr or noneunsetTitle written above the whole figure. Unset, none is written.
widthstr or noneunsetPrinted width: 'single', 'medium' or 'double' column. Unset, single for one panel, double for more panels or a facet.single (85 mm), medium (120 mm), double (180 mm)
facet'time' or 'run' or 'variable' or 'layer' or 'parameter' or noneunsetRepeat the one panel over this key.time, run, variable, layer, parameter
whenstr"end"When the figure is drawn: 'end', 'session' or 'after:<step>'.end, session, after:<step>, with <step> one of prepare_solver, run_solver, extract, derive, export
enginelist[str]["static"]Drawing engines to use for the figure, one file per engine.static, interactive
formatslist[str]["png"]File formats written for the figure, such as png or svg.png, svg, pdf

Fields of a panel

FieldTypeDefaultWhat it doesAccepted
typestr or noneunsetFrame of the panel. Unset, the natural frame of the variable.map, series, section, xy, distribution, groups, table, volume

timestr or int or list[str or int] or noneunsetA date (YYYY-MM-DD), 'first', 'last', a period index, or a list of them. A date picks the period (start, end] that holds it. On a series, two values keep the periods whose start lies between them.
layerint or str or noneunsetLayer index from 0 at the top, or 'sum' over the layers.sum, top

Frames#

A panel is drawn by one frame.

FrameWhat it drawsShapes it takesOverlays by default
mapMap frame: one value per mesh cell, drawn as filled polygons in the mesh CRS.time_layer_face, time_face, layer_face, facerelief, outline, network, outlet, scale_bar
seriesSeries frame: values along an ordered axis, the time of a run.time-
sectionSection frame: a vertical cut through the model along a line, distance against elevation.time_layer_face, layer_face, time_face, faceseepage
xyXY frame: one variable against another, one point per matched row.time, time_face, time_layer_face, layer_face, face-
distributionDistribution frame: the values of one variable against how often they occur.time, time_face, time_layer_face, layer_face, face-
groupsGroups frame: named categories against a value, as bars or as boxes.time, time_face, time_layer_face, layer_face, face-
tableTable frame: rows of text, a label and a value for each column a panel names.--
volumeVolume frame: the block of the model in 3D, coloured by one variable at one instant.--

Presets#

A preset is a request that lists the fields a user may fill.

PresetWidthPanels it expands to
hydrographdouble
  1. series variable = ["recharge"], station = "zone:catchment"
    Holes time
  2. series variable = ["discharge"], observed = true, scores = true, scale = "linear"
    Holes variable, station, scale, time
residualsdouble
  1. series variable = ["discharge"], scores = true, reference = ["zero"], against = "observed"
    Holes variable, station
  2. distribution variable = ["discharge"], against = "observed"
    Holes variable, station
water_budgetdouble
  1. series variable = ["budget"], station = "zone:catchment", stack = true
    Holes variable, station, time
  2. groups variable = ["budget"], station = "zone:catchment", reduce = "mean"
    Holes variable, station, time
watershed_id_carddouble
  1. map variable = ["topography"], overlays = ["relief", "outline", "outlet", "network", "stations", "scale_bar"]
  2. table variable = ["simulation.solver", "simulation.flow_regime", "simulation.period_start", "simulation.period_end", "simulation.n_timesteps", "simulation.n_cells", "simulation.n_layers"]
network_expansiondouble
  1. series variable = ["simulated_active_network"], station = "zone:catchment"
    Holes time
  2. series variable = ["discharge"], observed = true
    Holes station, time
