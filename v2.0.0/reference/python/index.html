Python API#

import hydromodpy as hmp. The functions below are the entry points of the package; the objects they return hold the results. The Command line column names the hmp command that is the twin of each function.

A minimal session#

import hydromodpy as hmp

run = hmp.run("path/to/config.toml").open()   # simulate, then open the Run
head = run.read("head")           # an xarray.DataArray
run.figure("water_budget")   # draw a shipped preset

proj = hmp.open("path/to/project")     # reopen the project later, read only
run = proj["baseline"]                 # one of its runs, by name

How these objects relate, and what Run.read returns for each kind of variable, is on Objects and how they relate. What can be raised, with the HMPY.Exxx codes, is on Exceptions and error codes.

Stability#

This page documents hydromodpy 2.0.0. The public surface is the 52 names of hydromodpy.__all__ (17 functions, 7 classes, 27 exceptions and 1 other names), the classes they return, and the exceptions of this reference. A name outside this reference is internal, except the modules for extensions on the contracts page. So is the hydromodpy.project.api module.

This is a final release: a name listed here changes only under the rules of the versions page. Versions follow semantic versioning with PEP 440 pre-release tags. What each kind of version may change is on the versions page.
