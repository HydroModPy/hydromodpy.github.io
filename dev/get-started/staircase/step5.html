Step 5: every export#

Task

Write the results of step 4 in every format HydroModPy can export, and ask for more files once the run exists.

Time

1 to 2 min for the run, 1.5 to 3 min for the command.

Needs

The example files (The staircase). Nothing is downloaded.

Gives

Eight figures and thirteen files, from GeoPackage to VTU.

Step 5 does not change the model. It is step 4 with its results written out in every format HydroModPy can export. The file drops the inherited exports with export__delete = true and states its own list, one [[export]] block per request. A block says what (variables), when (time or period), and where and how (format, file, crs).

The map is the field of one of the exports below, watertable_depth_2002-10-15.tif, drawn.

Run it#

hmp run step5_export.toml
hmp export nancon_step5_export --list

--list prints what the run can export, by kind, and writes nothing.

import hydromodpy as hmp

run = hmp.run("step5_export.toml").open()

Once the run exists, hmp.export(run, ["head", "watertable_depth"], time="2002-10-15") writes more files and returns their paths.

What you get#

Ten export blocks write thirteen files, in runs/nancon_step5_export/exports/. The format follows the data unless the block says otherwise: a vector layer is a GeoPackage, a series or a table is a CSV, and a field at one instant is a GeoTIFF.

The Shapefile is one block and several files (.shp, .dbf, .prj, .shx, .cpg), which the run counts as one export. Every export carries the identity of the run: a GeoPackage in its metadata table, any other file in a .meta.json beside it, and exports/index.json lists them all. The portable archive of the run is a copy out of the project: hmp publish nancon_step5_export --to nancon.tar --container tar. By default it holds the results, the final state, the DEM, the GeoPackage and the station series the run read, the sealed mesh and products.json, and hmp catalog import nancon.tar installs them in another workspace (Share a simulation with its data).

Eight figures, drawn from the same data: the presets watershed_id_card, water_budget and hydrograph, and the variables watertable_depth, seepage_mask, network_agreement, downslope_distance and simulated_active_network.

Once a run exists you can also ask for files without editing the TOML, for example hmp export nancon_step5_export head watertable_depth --time 2002-10-15.

Key fields#

[[export]]
variable = "head"What to export: a name, a list of names, or "all" for everything the run holds. required example value
Path
export.variable
More

One namespace covers the mesh fields (head, watertable_depth, seepage_mask..., and mesh_cell_area, which "all" leaves out because mesh_cells holds it), the series (discharge, discharge_obs...), the vector layers (watershed, hydrographic_network_reference...), the three layers of the cell mesh (mesh_cells, mesh_seeds, mesh_family_faces), the raster layers (watershed_dem...) and the table budget; 'hmp export <run> --list' prints what a run holds. A name no run can hold is refused before the solve.

Accepted
string or list of string
Example
"head", ["head", "discharge"], "all"
# time = ‹string or integer or list of string or integer›The instants to write: a date "YYYY-MM-DD", "first", "last", or a list of them.
Path
export.time
More

A date takes the stress period that holds it. A format that holds one instant (GeoTIFF, Shapefile, GeoPackage, VTU) writes one file per date. Left out, the whole simulation is written. Cannot be given with period.

Accepted
string or integer or list of string or integer
# format = ‹string›The file format, a name the export registry serves.
Path
export.format
More

Left out, each data takes its natural format, or the one the extension of 'file' names. A view format describes the whole run and takes variable = "all" only. The portable archive of a run is written by 'hmp publish --container tar'.

Accepted
string
# file = ‹path›One exact file to write; its extension gives the format.
Path
export.file
More

Relative to 'folder' under runs/<run>/exports/; an absolute file or one that climbs out with '..' is refused. Only for a request that writes one file: several files need 'folder' and automatic names.

Accepted
path
[[export]]
variable = "head"
# time = <string or integer or list of string or integer>
# format = <string>
# file = <path>

Lines generated from the models, as in the reference. Open one for its card.

The other keys of a block are export.period, export.crs and export.folder.
