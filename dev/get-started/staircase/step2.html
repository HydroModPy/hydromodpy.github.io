Step 2: the mapped network and the gauge#

Task

Compare the cells where the simulated water table reaches the surface with the mapped river network and the gauge.

Time

15 to 25 s for the run, 40 to 60 s for the command.

Needs

The example files (The staircase). Nothing is downloaded.

Gives

Four figures and five files, with the mapped network among them.

Step 2 adds two pieces of data, read from local files: the mapped stream network and the discharge gauge at the outlet. The run is still steady. The point is the comparison: the cells where the simulated water table reaches the surface should lie where the map draws a stream. The figures show where they agree and how far each simulated cell is from the map.

Run it#

hmp run step2_local_data.toml

import hydromodpy as hmp

run = hmp.run("step2_local_data.toml")

The network is the GeoPackage nancon_stream_network.gpkg, which hmp example add put in data/hydrography/. The gauge is the NANCON station of data/hydrometry/, a daily record from 1982 to 2022. Nothing is downloaded. The run prints the same first two warnings as step 1: they are explained there.

What you get#

display.figures is a list, so step 2 replaces step 1’s list. Four figures:

Figure

What it shows

watershed_id_card

As in step 1

hydrographic_network_reference

The mapped network alone

seepage_network_confusion_map

Three classes: valid where the two networks share a cell, excess where only the model has a stream, missing where only the map has one

downslope_distance_map

How far each simulated cell must descend before it reaches the mapped network, in four classes: 0 to 75 m, 75 to 500 m, 500 to 1000 m, and more than 1000 m

Step 1’s three exports are inherited. [[export__append]] adds a fourth block: the mapped network, as a GeoPackage. Five files land in share/nancon_step2_local/.
