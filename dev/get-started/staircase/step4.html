Step 4: the transient run#

Task

Run the model month by month over 2000-2002 and see which cells flow, and for how long.

Time

1 to 2 min for the run, 1.5 to 3 min for the command.

Needs

The example files (The staircase), which hold the observed recharge and runoff. Nothing is downloaded.

Gives

Five figures and seven files, among them a NetCDF of the water table and a CSV of the discharge.

Step 4 turns step 2 into a monthly transient run over 2000-2002. The recharge and the runoff are no longer one mean: 36 monthly values replace the steady rate. The first period is solved steady and gives the initial heads. K, Sy and Ss are assumed here, not calibrated. The question changes from where the water table reaches the surface to which cells flow, and for how long. The baseflow warning of steps 1 and 2 is gone: the runoff is loaded and added to the discharge.

Run it#

hmp run step4_transient.toml

import hydromodpy as hmp

run = hmp.run("step4_transient.toml")

This is also what py1_run_and_plot.py of the example does, before it draws its own figure. After the staircase lists the scripts.

Two points of the file are worth a second look. flow.flow_regime is written again, because an inherited "steady" is not undone by the default. data.types is written in full, because a list replaces the parent’s.

What you get#

Five figures. The instant of the one-instant figures comes from display.time, here 15 October 2002, the driest month according to the file.

Figure

What it shows

flux_timeseries

The components of the water balance through time, inflows positive and outflows negative

hydrograph_sim_obs

The simulated discharge against the gauged one

seepage_map

The seepage cells of October 2002

flow_persistence_map

The share of the three years each cell flows: dark where the channel ran all year, pale where it ran only at the wettest steps

flow_intermittence_map

One calendar year, 2002 (cycle = "2002"): each cell is perennial, intermittent or dry

Six export blocks write seven files in share/nancon_step4_transient/: the five files of the inherited blocks, now of a transient run (the GeoTIFFs hold December 2002, the last month), and two more.

Block

File

the water table over the 36 months, one NetCDF file

["discharge", "discharge_obs"]

simulated and gauged discharge, a CSV: the model monthly, the gauge daily

# time = ‹string or integer›The instant every figure that draws one instant shows: a date ("2002-10-15"), "first" or "last".
Path
display.time
More

Each such figure draws the stress period that holds the date, so the same date names the same month on a monthly, a daily or a one-period steady run. A time in [display.overrides.<figure>] wins over it. Unset, each figure picks its own instant: the last period, or for the stream-network maps the state their calibration criterion read. A date outside a run skips the figure with the reason.

Accepted
string or integer
[display]
# time = <string or integer>

Lines generated from the models, as in the reference. Open one for its card.

The time step is not written: simulation.time.step_value defaults to one month.
