HydroModPy#

A Python toolbox for automated, reproducible, catchment-scale modelling of shallow groundwater. One TOML file takes a catchment from its digital elevation model to a calibrated model: where the water table sits, where it reaches the ground, which streams it keeps flowing, and how all of it changes with the seasons.

Important

This documentation follows the 2.0 pre-release line, version 2.0.0a5. Install it with pip install --pre hydromodpy. Projects written for version 1 should stay pinned to an exact tag such as v1.0.0.

Theory

What HydroModPy does#

Physically based groundwater models are expensive to deploy at the scale of a catchment: data, mesh, parameters, calibration and post-processing rarely follow the same path from one site to the next. HydroModPy turns the construction, the run, the calibration and the analysis of a shallow groundwater model into one workflow that can be replayed on many catchments, with the same inputs and the same outputs.

It automates the steps that take the most time:

  1. Catchment extraction from a digital elevation model.

  2. Forcing and observations: recharge, climate series, groundwater heads, gauged discharge, mapped stream networks and intermittency.

  3. Mesh and vertical discretisation suited to shallow basement aquifers, with parameters given per zone or per cell, in steady state or in transient.

  4. Calibration that combines heads, discharge and the extent of the stream network to constrain the hydraulic properties.

  5. Outputs that can be reopened, stored with their provenance and the licence of the data they come from, then drawn as figures or exported to standard formats.

First a FloPy-driven MODFLOW-NWT toolbox, HydroModPy now runs several solvers behind one configuration validated by Pydantic, and stores its runs in a columnar layout (DuckDB catalog, Zarr fields, Parquet tables) that makes them reproducible and easy to inspect.

Highlights#

Several solvers, one file

MODFLOW 6, MODFLOW-NWT and a Boussinesq solver for the flow; MODFLOW 6, MT3DMS and MODPATH for solutes and particles.

Solvers
A typed configuration

One HydroModPyConfig root, every key typed and checked by Pydantic. The hmp command runs the same file without writing any Python.

TOML parameters
From a DEM to a model

Catchment delineation, forcing, mesh and observations from one configuration, with public data downloaded and cached.

Data sources
Calibration

Heads, discharge and mapped stream networks combined into calibrations you can replay, on the distributed model or on a lumped GR4J model.

Calibration methods and metrics
Results you can reopen

A catalog of runs, Zarr fields and Parquet tables, with exports to standard geospatial formats.

hmp catalog
Checked against references

Every validation test: the reference it compares with, the solvers it runs and the thresholds it must stay under, read from the tests.

How to cite#

If HydroModPy supports your work, please cite the companion technical note, published in Hydrology and Earth System Sciences (2026, doi:10.5194/hess-30-5571-2026), and the software, archived on Zenodo (doi:10.5281/zenodo.22141925). Cite gives BibTeX, RIS and plain-text versions; CITATION.cff at the root of the repository is what GitHub shows behind “Cite this repository”.
