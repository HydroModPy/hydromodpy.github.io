Environment variables#

Built from hydromodpy/core/env.py; the files that read each variable come from a scan of the code each time the site is built. Fix a wrong row there.

47 variables. tests/unit/architecture/test_env_vars_are_registered.py fails when the code names a HMP_* variable that has no row in the registry, or when a row names a variable nothing reads.

For users#

Variables a person running HydroModPy may set.

Variable

When unset

What it does

Read in
HMP_AUTH_BACKEND

local

Name of the backend that says who acts, for the audit trail and the privacy purge. Only local ships. An unknown name raises ValueError.

hydromodpy/core/auth/selection.py; 1 test file
HMP_AUTO_MIGRATE

on

0, false, no or off forbids the automatic schema upgrade of a DuckDB file when it is opened. A needed upgrade then raises AutoMigrationDisabled.

hydromodpy/core/migrations/auto_boot.py; 2 test files
HMP_AUTO_REGISTER_PROJECT

on

0, false, no or off stops the registration of project roots in the global index of the machine.

hydromodpy/core/state/global_index.py, validation_cases/shared/runtime.py; 2 test files
HMP_BIN

bin/ under the cache folder

Folder of the solver binaries. Replaces the managed folder under HMP_CACHE_HOME.

hydromodpy/core/workspace/workspace.py, tools/docs/check_quickstart.py; 3 test files
HMP_CACHE_HOME

the user cache folder of the platform

Root of the machine cache: solver binaries and downloaded data.

hydromodpy/core/state/paths.py, tools/docs/check_quickstart.py; 8 test files
HMP_EXAMPLES_SOURCE

the GitHub tag of the installed version

Replaces the whole prefix the example files are fetched from: a URL, a file:// URL or a local checkout. When it is set, --ref no longer applies.

.github/workflows/docs-get-started.yml, hydromodpy/examples/blobs.py; 1 test file
HMP_NO_PROGRESS

unset

Any non-empty value turns off the live progress display on the console.

hydromodpy/core/progress.py, hydromodpy/data/request/job.py, hydromodpy/spatial/domain/capability.py and 1 more; 2 test files
HMP_PROGRESS_FILE

unset, no file

Path of an NDJSON file. Each progress event is appended to it as one JSON line, for a supervisor that reads the file while the run goes on.

hydromodpy/core/progress_ndjson.py
HMP_PROJECT_ROOT

[workspace] project_root, then the folder of the config file

Project root of a run. Wins over [workspace] project_root of the TOML.

hydromodpy/cli/commands/run.py, hydromodpy/config/hydromodpy_config.py, hydromodpy/core/workspace/path_registry.py and 3 more; 7 test files
HMP_SET_<key>

unset

hmp run reads each variable that starts with HMP_SET_ as a TOML override. The rest of the name is the key, lowercased, with __ for a dot: HMP_SET_simulation__run_id. The value is parsed as TOML. It wins over --set.

hydromodpy/cli/commands/run.py
HMP_SILENCE_MF6_VERSION_MISMATCH

unset, the warning is shown

Any value other than empty, 0, false or no silences the warning shown when the MODFLOW 6 executable and libmf6 differ in major or minor version.

hydromodpy/solver/modflow_common/binaries.py
HMP_STATE_HOME

the user state folder of the platform

Root of the machine state, where the global index index.duckdb lives. The test suite points it at its scratch folder.

hydromodpy/core/state/paths.py; 8 test files
HMP_USER

USER or USERNAME, then the system user

Name of the person who acts, written in the audit trail.

hydromodpy/core/auth/backends.py; 2 test files
HMP_VERBOSITY

normal

Console verbosity: quiet, normal, verbose or debug. The command line reads --verbosity first, then this variable, then [workflow] verbosity.

hydromodpy/core/logging.py, hydromodpy/data/request/job.py, hydromodpy/spatial/domain/capability.py and 1 more; 2 test files
HMP_WORKSPACE

the workspace found above the current folder, then ~/hydromodpy

Workspace root of the catalog, project and run commands when the command line gives none.

hydromodpy/cli/_workers/catalog.py, hydromodpy/cli/_workers/project.py, hydromodpy/cli/commands/catalog/ls.py and 7 more; 9 test files

For debugging#

Variables that trace or keep intermediate files, or that HydroModPy sets itself.

Variable

When unset

What it does

Read in
HMP_ALLOW_LEGACY_NPY_VALIDATION

unset, refused

1 lets the loaders of the validation cases read results saved as legacy .npy files.

validation_cases/shared/loaders.py
HMP_DETERMINISTIC_FETCHED_AT

unset, the fetch time is written

1 writes no fetched_at in the provenance sidecar of a downloaded file, so the sidecar is the same bytes on every run.

hydromodpy/data/provenance/sidecars.py
HMP_GMSH_VERBOSE

unset, Gmsh is silent

1, true, yes or on keeps the terminal output of Gmsh.

hydromodpy/spatial/mesh/gmsh_grid/zone_meshing/_gmsh_occ.py
HMP_KEEP_TRIAL_SCRATCH

unset, removed

Any value other than empty, 0, false or no keeps the solver folder of each calibration trial and the preprocessing tree of the session.

hydromodpy/calibration/runners/sandbox.py; 3 test files
HMP_MESH_TRACE_FILE

unset, no trace

Path of a text file. Each stage of the Gmsh meshing appends one timestamped line to it.

hydromodpy/spatial/mesh/gmsh_grid/trace.py
HMP_OUT_PATH

hydromodpy_validation_outputs in the system temporary folder

Output root of the validation cases and of the investigation scripts under tools/. The validation results land under <HMP_OUT_PATH>/validation.

tools/investigate_linux_nwt_boussinesq_transient.py, tools/investigate_sloping_substratum_transient.py, tools/investigate_surface_interaction_hillslope.py and 6 more; 4 test files
HMP_OVERVIEW_HTML_REVIEW_LEVELS

unset

1, true, yes or on also writes the review pages of the data overview report (compact, standard, audit) and links them.

hydromodpy/display/overview/report.py, hydromodpy/display/overview/web.py
HMP_PANDERA_STRICT

unset, a warning is logged

1, true, yes or on makes a failed pandera schema check of an ingested table raise instead of logging a warning.

hydromodpy/data/schemas/validation.py
HMP_RUN_SCRATCH

unset outside a run

Set by HydroModPy, never by hand: the scratch folder of the run this process is inside. A subprocess inherits it and works in the same folder.

hydromodpy/core/state/paths.py; 1 test file
HMP_VALIDATION_RESULTS_FILE

unset, the snapshot committed in docs/source/theory/

A results file written by tools/docs/validation_results.py merge that a docs build reads instead of the committed snapshot, to show fresh local measures without changing a tracked file.

docs/source/_ext/hmp_validation.py
HMP_WHITEBOX_REDIRECT_NATIVE_STDIO

redirect outside pytest, not under pytest

Forces whether the native output of Whitebox is redirected at the file descriptor level. The test suite sets 0.

hydromodpy/spatial/delineation/whitebox_workflows_backend/raster.py; 2 test files
HMP_WHITEBOX_VERBOSE

unset, quiet

A true value (1, true, yes, on) turns on the verbose mode of Whitebox.

hydromodpy/spatial/delineation/whitebox_workflows_backend/raster.py

HMP_UPDATE_GOLDEN

tests/unit/mesh/cartesian_grid/field_discretization/test_sgrid_fieldparam_discretization.py

unset, nothing recorded
