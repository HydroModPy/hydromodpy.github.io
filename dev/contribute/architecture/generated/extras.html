Optional dependencies#

Built from [project.optional-dependencies] of pyproject.toml each time the site is built. Fix a wrong row there.

Imported by: the sub-packages of hydromodpy that import a module of the group, found by reading the imports. A group that no package imports serves the tools around the code: tests, documentation, editors.
