Storage tree#

Built from hydromodpy/results/storage/contract.py, hydromodpy/core/state/paths.py and hydromodpy/schema/generated_views.py each time the site is built. Fix a wrong row there.

Each name below is a constant or a path helper of one of these modules, named as <module>.<name>; the meaning is its docstring. The tables list the entries in the order of the tree. tests/unit/results/test_run_layout_contract.py checks a real run against the same constants.

Project#

A run directory may hold only the entries listed under <run>/.

<project>/
    project.toml
    configs/
    runs/
        <run>/
            fields.zarr/
            tables.parquet/
                <view>.parquet
            config.toml
            provenance.json
            manifest.json
            annotations.json
            trash.json
            figures/
            ro-crate-metadata.json
            stac-item.json
            prov.jsonld
            .hmp/
    sessions/
        <session>/
            session.json
            trials.jsonl
            trial_series/
                trial-000001.parquet
    share/
        reports/
    .hmp/
        index.duckdb
        scratch/
            <run>.p<pid>/
                _preprocessing/

Entry

Declared by

Meaning

<project>/

-

One project, the root of its runs and sessions.

project.toml

 paths.PROJECT_MARKER_FILENAME

The project configuration file, and the marker of a project root.

configs/

 paths.CONFIGS_DIRNAME

Reserved sub-directory holding the config variants of a project.

runs/

 paths.RUNS_DIRNAME

Directory holding one sub-directory per run at <project>/runs/<name>.

<run>/

-

One run, named after the run itself, with its .vN version suffix.

fields.zarr/

always written

 contract.FIELDS_STORE_NAME

Zarr directory store of one run.

tables.parquet/

always written

 contract.TABLES_DIRNAME

Directory grouping the Parquet payloads of one run.

<view>.parquet

 contract.PARQUET_FILE_SUFFIX

Suffix of a single Parquet payload inside TABLES_DIRNAME.

config.toml

 contract.RUN_CONFIG_FILENAME

Frozen resolved configuration of one run.

provenance.json

 contract.RUN_PROVENANCE_FILENAME

Environment, versions and git state of one run.

manifest.json

 contract.RUN_MANIFEST_FILENAME

Seal of a complete run directory. Absent means the run did not finish.

annotations.json

 contract.RUN_ANNOTATIONS_FILENAME

Tags and notes of one run. Written after the seal, like the trash marker.

trash.json

 contract.RUN_TRASH_FILENAME

Trash marker of one run. Present means trashed; absent means live.

figures/

 contract.RUN_FIGURES_DIRNAME

Figures rendered for one run.

ro-crate-metadata.json

 generated_views.RO_CRATE_VIEW_FILENAME

RO-Crate 1.1 metadata. The name is fixed by the RO-Crate specification.

stac-item.json

 generated_views.STAC_ITEM_VIEW_FILENAME

STAC 1.0 Item describing the directory as one catalogue entry.

prov.jsonld

 generated_views.PROV_VIEW_FILENAME

W3C PROV-O lineage as a standalone JSON-LD document.

.hmp/

 contract.RUN_SCRATCH_ENTRIES

Runtime scratch a live run holds, which is not a result.

sessions/

 paths.SESSIONS_DIRNAME

Directory holding calibration and spin-up sessions.

<session>/

-

One calibration or spin-up session.

session.json

 contract.SESSION_DESCRIPTOR_FILENAME

Identity, search space, objective, best trial and root search of one session.

trials.jsonl

 contract.SESSION_TRIALS_FILENAME

Trial journal of one session, appended one JSON object per line as it runs.

trial_series/

 contract.SESSION_TRIAL_SERIES_DIRNAME

Opt-in per-trial simulated/observed series, one Parquet file per trial.

trial-000001.parquet

 contract.session_trial_series_filename

Return the file name of one trial’s series table, sortable by trial number.

share/

 paths.SHARE_DIRNAME

Directory holding on-demand exports and portable packages.

reports/

 paths.REPORTS_DIRNAME

Report sub-directory of SHARE_DIRNAME.

.hmp/

 paths.INTERNAL_DIRNAME

Disposable internals: index database, trash, scratch, logs, cache.

index.duckdb

 paths.CATALOG_FILENAME

Project index database living at <project>/.hmp/index.duckdb.

scratch/

 paths.scratch_root_for

Return <root>/.hmp/scratch, which holds the scratch folder of every run.

<run>.p<pid>/

 paths.scratch_dir_for

Return the solver working directory of the current run.

_preprocessing/

 paths.PREPROCESSING_DIRNAME

Folder of the geographic, data and mesh preprocessing, inside a run’s scratch.

Workspace#

A workspace groups projects.

<workspace>/
    workspace.toml
    projects/
        <project>/

Entry

Declared by

Meaning

<workspace>/

-

A folder that holds several projects.

workspace.toml

 paths.WORKSPACE_TOML_FILENAME

Workspace-wide metadata file living at <workspace>/workspace.toml.

projects/

 paths.PROJECTS_DIRNAME

Workspace sub-directory holding one directory per project.

<project>/

-

One project, laid out as above.

Machine#

Folders outside any project, shared by every project of the machine.

<state>/
    index.duckdb
<cache>/

Entry

Declared by

Meaning

<state>/

 paths.state_dir

Return platform state dir (HMP_STATE_HOME override). Set by HMP_STATE_HOME.

index.duckdb

 paths.INDEX_FILENAME

Machine-wide global index file living under state_dir().

<cache>/

 paths.cache_dir

Return platform cache dir (HMP_CACHE_HOME override). Set by HMP_CACHE_HOME.

Storage layers#

Where each kind of result is stored.

Layer

Scope

Path

Role

project

Project-level DuckDB index for runs, metadata, metrics, and provenance.
zarr

run

 <project>/runs/<run>/fields.zarr

Per-run array store for meshes, spatial fields, forcings, and rasters.
parquet

run

Per-run tabular payloads exposed through DuckDB views.
