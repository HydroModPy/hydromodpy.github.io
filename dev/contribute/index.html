The four blocks#

  • Recipes (Recipes): one page per extension, with the files to touch, the contract to honour and the test to add.

  • Architecture (Architecture): the layers and their allowed imports, the packages, the storage layout and the subsystems.

  • Documentation (Documentation): how this site is built, and how to write a field or a theory page.

  • Project (Project): CI, tests, the V1 release contract, the environment variables and the roadmap.
