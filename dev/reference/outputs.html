Outputs of a run#

A run stores its field arrays in fields.zarr and its station series in tables.parquet/timeseries.parquet. Both lists below are read from the field registry of the code. A name added to the registry shows up here at the next build.

Field arrays#

Each group is the first folder of the path in the store. The fields under budget/ follow one sign rule, set in the registry.

Top level

NamePath in the storeUnitDimensionsWhat it holds
headheadmtime, layer, faceGroundwater head (per layer and UGRID face)
concentrationconcentrationkg m-3time, layer, faceSolute mass concentration in groundwater, one solute per run, read under concentration/<spc_name> or, for a run written by a pre-release, under the flat concentration array
face_flowface_flowm3 s-1time, connectionVolume flow from the first to the second cell of each connection, mean of the steps of each saved period
connection_cellsconnection_cells1connection, twoFlat index (layer x faces + face) of the two cells of each connection, the smaller first
