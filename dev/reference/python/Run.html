class Run(sim_id, catalog, *, read_config=None, render=None)[source]#

Read one persisted simulation from a HydroModPy catalog.

Run is a lightweight view over one row in the simulations table. It exposes metadata, tabular outputs, field arrays, geographic features, and convenience helpers without requiring callers to know whether data are stored in DuckDB, Parquet, or Zarr.

Parameters:

  • sim_id (str) – Simulation UUID stored in the catalog.

  • catalog (Catalog) – Open Catalog that owns the run metadata and storage paths.

Raises:

hydromodpy.results.errors.RunNotFoundError – On first attribute access if sim_id is not present in the catalog.

Examples

>>> import hydromodpy as hmp
>>> proj = hmp.open("~/hmp_workspace/projects/nancon")
>>> run = proj["baseline"]
>>> run.label()
>>> run.field("head", time=-1)

See also

hydromodpy.results.catalog.facade.Catalog

Workspace-level catalog that creates Run instances.

hydromodpy.results.run.group.RunSet

Collection view for many runs.

Export data of this run to files; return the files written.

The words of an [[export]] block: variable says what (a name, a list, or "all"), time or period when, folder or file where. The format follows the data unless format or the extension of file names one: a field at one date goes to GeoTIFF, over several dates to one NetCDF, a series or the budget to CSV, a vector layer to GeoPackage, a raster layer to GeoTIFF. Files land in runs/<run>/exports/; a relative folder or file is read from there. Each file carries the identity of the run and is recorded in exports/index.json.

Examples

>>> run.export("all")
>>> run.export(["head", "watertable_depth"], time="2001-08-15")
>>> run.export("discharge", period=("2001-01-01", "2002-12-31"))
>>> run.export(
...     "watertable_depth", time="last", file="nappe_wgs84.tif", crs="EPSG:4326"
... )

Run.read(variable, *, time=None, layer=None, sel=None, bbox=None)[source]#

Read a variable of this run, one type for each nature of variable.

  • a field gives an xarray.DataArray with the dimensions time, layer and cell it has. One period in time removes time.

  • a time series gives a pandas.Series indexed by date. It takes sel and no time.

  • a geographic feature gives a geopandas.GeoDataFrame, one row per shape. It takes no time.

  • "particles" gives a pandas.DataFrame, one row per recorded position. It takes no time.

Every field the run reports through has_field reads back here. A stored field is lazy when dask is installed. Fields rebuilt on the fly (water-table elevation and depth, seepage mask, drain outflow) are loaded at once, and time is ignored for a field without a time axis.

Parameters:

  • variable (str) – Name resolved against the field registry, then the timeseries table, then the geographic features.

  • time (Any) – The period of a field: an index (negative counts from the end), a date that resolves to the stress period holding it, "first" or "last", or a slice of indexes. None keeps every period.

  • layer (int | None) – Layer index of a three-dimensional field, 0 for the top layer.

  • sel (dict | None) – Selectors of the reader: {"station": ...} for a series, {"period": (start, end)} for a window of dates.

  • bbox (tuple[float, float, float, float] | None) – (xmin, ymin, xmax, ymax) in the CRS of the run; keeps the cells whose centre lies in the box.

Raises:

  • hydromodpy.results.errors.FieldNotFoundError – If no reader resolves variable.

  • ValueError – If time names a date outside the run, or is given for a series or a feature.

  • IndexError – If time is an index outside the run.

Examples

>>> head = run.read("head")
>>> last = run.read("head", time=-1, layer=0)
>>> ts = run.read("discharge", sel={"station": "outlet"})

Fields, rasters and mesh#

property Run.catchment_mask: ndarray#

the basin of D at the catchment outlet.

One value per mesh face, read-only, True for the faces of the basin stored as mesh/descent_basin. A run sealed before the basin was stored, a run with no descent (such as a Boussinesq run) and a run whose basin is only the largest one of a synthetic domain (no catchment) fall back, with an INFO line, to a 2D mask on the DEM raster, True where the DEM has a valid positive elevation; its shape is run.grid.shape. Cached on first access. The mask says which cells drain to the outlet; the share of each face inside the delineated polygon, which weighs a catchment total of a spatial quantity, is hydromodpy.results.derive.views.catchment_weights(run).

Type:

Boolean mask of the catchment

Run.field(variable, *, time=-1, layer=None, bbox=None)[source]#

Read one period of one field, persisted or recomputed on the fly, as an array.

Takes the words of Run.read(), for one period. Delegates to Catalog.query_field, which falls back to the virtual derivations (watertable elevation/depth, seepage mask, drain outflow) when the field is not persisted. This keeps has_field honest: a variable it reports as available always reads back as an array. Each call opens the store: many steps read through field_range().

Parameters:

  • variable (str) – Public field name registered in hydromodpy.results.field_registry.

  • time (int | str | date | Timestamp | datetime64) – One period: an index (negative counts from the end), a date that resolves to the stress period holding it, "first" or "last". The last by default.

  • layer (int | None) – Optional layer index, 0 for the top layer, for three-dimensional fields.

  • bbox (tuple[float, float, float, float] | None) – Optional (xmin, ymin, xmax, ymax) in the simulation CRS. Cells whose center (run.mesh.cell_centers()) falls outside the bounding box are set to NaN (for float dtypes) or 0 (for integer dtypes). The shape of the array does not change.

Returns:

numpy.ndarray – Field values for the requested time and layer selection.

Return type:

ndarray

Run.score(windows=None, metrics=None, months=None, station=None)[source]#

Score the stored series of this run again, on any window, after the fact.

No model is run: the series come from timeseries.parquet and are paired as the seal pairs them, a simulated stamp closing its period.

Parameters:

  • windows (Mapping[str, tuple[Any, Any]] | Sequence[DateWindow] | None) – {name: (start, end)} with ISO dates, either bound None for open, or a list of DateWindow. None scores the [metrics] window of the seal.

  • metrics (Sequence[str] | None) – Names of the metric table. None means every metric a series pair can give. A network metric is refused, and so is a metric that needs consecutive days when months is set.

  • months (Sequence[int] | None) – Calendar months, 1 to 12, that the paired periods must fall in.

  • station (str | None) – Score only this station. None scores every observed station the run simulates.

Returns:

pandas.DataFrame – One row per station, variable, metric and window: sim_id, run, station, variable, metric, window_name, window_start, window_end, months, value, n_samples, n_sim_nan.

Return type:

DataFrame

Run.score_network(output=None, window=None)[source]#

Score the stream-network criterion of this run again, as its trial scored it.

No model is run. The release field, the mesh, the maps and the criterion recharge come from the store, and the settings from the network output the run sealed, or the defaults of that output when it sealed none. The value is the one a calibration trial gives at the same parameters and window.

Parameters:

  • output (str | None) – The sealed network output to read. None reads the only one, or the defaults.

  • window (tuple[Any, Any] | Mapping[str, tuple[Any, Any]] | None) – (start, end) or {name: (start, end)}, ISO dates, either bound None for open. It picks the complete years of the two-bound mode. None reads the window the run was scored with, else every year. One state reads no window.

Returns:

pandas.DataFrame – One row per quantity: sim_id, run, output, mode (one_state or two_bounds), window_name, window_start, window_end, bound (minimal, maximal, a validation map, or empty), year (empty for the climatological value), quantity (J_signed, D_so, D_os, D_optim, r_optim_valid, n_years_scored, …) and value.

Return type:

DataFrame

property Run.time_index: DatetimeIndex#

Datetime index aligned with the simulation’s stress periods.

Length matches run.n_timesteps. Each stamp is the END of its period, as the solvers write it. The solver’s CF /time axis is read first; without it the stamps are rebuilt from the period_start, period_end and time_unit the run states about itself. A steady run without [simulation.time] records no step count and holds one state: its index is the one stamp the solver wrote on its axis, a clock with no calendar that starts at 1970-01-01, so every reader gets one stamp per stored state. Raises if the bounds are missing or a transient simulation has no timesteps.

Return one time series, simulated unless source says otherwise.

Parameters:

  • variable (str) – Catalog variable name, such as "discharge" or "head".

  • station (str | None) – Station id stored in the timeseries table. Left None, it is the only station of the variable, or the whole catchment when it has one. A run with several observed piezometers or lakes stores a series for each, and the catchment has none for a head or a stage, so those reads need station; the error lists the ids.

  • period (tuple | str | None) – Optional window, (start, end) or a year as text ("2002"). It keeps the stress periods it overlaps, as a field or a CSV export reads it: a simulated value by its stamp, (lo, hi], an observation by its date, [lo, hi). One date reads the period that date reads.

  • downsample (str | None) – Optional decimation strategy. "lttb" runs Largest Triangle Three Buckets on the series; "auto" enables LTTB only when the series exceeds 50_000 points; None (default) returns the untouched full-resolution series.

  • n_out (int | None) – Target sample count for downsample="lttb" or "auto". Defaults to 5000.

  • source (str) – "simulated", the default, or "observed" for the measurement of the same variable.

Returns:

pandas.Series – Time-indexed values with timezone-normalized UTC timestamps.

Raises:

KeyError – Raised when no matching time series exists.

Series
