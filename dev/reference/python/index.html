Python API#

import hydromodpy as hmp. The functions below are the entry points of the package; the objects they return hold the results. The Command line column names the hmp command that is the twin of each function.

A minimal session#

import hydromodpy as hmp

run = hmp.run("path/to/config.toml")   # simulate: returns a Run
head = hmp.read(run, "head")           # a lazy xarray.DataArray
hmp.figure(run, "flux_timeseries")   # draw one registered figure

cat = hmp.open("path/to/project")      # reopen the catalog of the project later
run = cat.latest()                     # the newest run in it

How these objects relate, and what hmp.read returns for each kind of variable, is on Objects and how they relate. What can be raised, with the HMPY.Exxx codes, is on Exceptions and error codes.

Stability#

This page documents hydromodpy 2.0.0a5. The public surface is the 126 names of hydromodpy.__all__ (15 functions, 95 classes, 13 modules and 3 other names), the classes they return, and the exceptions of this reference. A name outside this reference is internal, and so are the hydromodpy._api module and the hydromodpy.cli._workers package.

This is an alpha release: the API, the configuration, the storage and the behavior can still change from one alpha to the next, and a name listed here can be renamed or removed. Versions follow semantic versioning with PEP 440 pre-release tags, and no compatibility shim is kept for a removed name: see the release policy.
