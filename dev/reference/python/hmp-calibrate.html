hmp.calibrate()#

Found in the code
  • Command line hmp calibrate
  • Returns CalibrationReport, StagedCalibrationReport
  • Type aliases ConfigLike (str | os.PathLike[str] | HydroModPyConfig)
  • Defined in hydromodpy/_api.py
calibrate(
config,
*,
phase=None,
list_phases=False,
expand=False,
**kwargs,
)[source]#

Run a calibration workflow from a TOML file or config object.

Paths route directly to run_calibration_cli(); in-memory config objects open a lazy Project so run_calibration_programmatic() has the project context it requires.

A TOML declaring [[calibration.phases]] routes to run_staged_calibration(): each phase calibrates its own parameters and freezes them for the next. The same declaration carried by an in-memory config object routes there too: calibrate() writes the document a staged run needs next to the project’s sessions/ and runs it from there.

Parameters:

  • config (ConfigLike) – Path of the calibration TOML file (str or pathlib.Path), or a validated HydroModPyConfig.

  • phase (str | None) – Run only the named phase. It still needs the parameters its dependency froze, so a phase whose dependency has not run is refused rather than calibrated against un-frozen values.

  • list_phases (bool) – Return the declared phases without running anything. Each names the method it runs; a phase that names none gets the one its criteria call for, and method_reason says why. interval_width gives the width the phase reads its interval with and where it comes from: written in the phase, in [calibration.uncertainty], or the default that follows what the phase scores. A phase that moves again a parameter an earlier phase passes on also names that phase, and says whether its engine starts from the passed value.

  • expand (bool) – Return the [calibration] section a protocol unfolds into, instead of running anything. Needs config to be a TOML path. A file naming a protocol gets the whole section it unfolds into, without the protocol key, so it can be pasted in its place; a file naming none gets its own section back unchanged. Refused together with phase or list_phases: expand answers what would run, it does not run it.

  • kwargs (Any) – Options forwarded to the underlying calibration runner. The headless keyword controls the project initialization for the in-memory config branch and is ignored for the TOML branch (which builds no project). return_report=False returns the to_dict() payload of the report instead of the report.

Returns:

CalibrationReport or StagedCalibrationReport or list or dict – A run returns a report object, whatever the source of the configuration: a CalibrationReport for a calibration without phases (best_parameters, best_objective, best_sim_id, session_id), a StagedCalibrationReport for one that declares [[calibration.phases]] (phases, each with its own CalibrationReport, and frozen). A list of phase descriptions when list_phases is set. A dict with "calibration" and "protocol" keys when expand is set: "protocol" is None for a file naming no protocol, else a dict with "name", "version", "citation" (the first reference, short form) and "inherited" (true when the protocol comes from the base_config).

Raises:

  • FileNotFoundError – If the calibration TOML path does not exist.

  • ValueError – If expand is combined with phase or list_phases, or given a config object instead of a TOML path.

  • hydromodpy.core.exceptions.ConfigError – If the configuration cannot be read and the answer depends on reading it (phase, list_phases or expand).

  • hydromodpy.core.exceptions.ConfigMissingError – If neither config_path nor parameters is supplied.

  • hydromodpy.core.exceptions.CalibrationError – If a staged calibration cannot be run as declared, if phase names a phase the configuration does not declare, or if the optimizer or objective evaluation fails.

Return type:

CalibrationReport | StagedCalibrationReport | list[dict[str, Any]] | dict[str, Any]

Examples

>>> import hydromodpy as hmp
>>> report = hmp.calibrate("calibration.toml")

Keyword arguments and command-line flags#

The twin command is hmp calibrate.

KeywordDefaultCommand-line flagAccepted by
phaseNone--phaseevery form
list_phasesFalse--list-phasesevery form
expandFalse--expandevery form
headlessno flagevery form

Flags of hmp calibrate with no keyword: --check. To get their effect from Python, build the configuration object with the values you want, or write them in the TOML file.
