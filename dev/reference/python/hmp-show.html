Read one thing of a run, a session, a set of runs or a project.

what names a line of hydromodpy.project.show.SHOWN:

summary (run, session, project) a dict of facts; profile (run, session) where the time went; table (run, session, set) the sealed table name; field and series (run) the variable name at time, layer, sel, bbox; point (run) the variables name in the cell point (x, y, cell, depth, label) at layer and the time step time; rank (project) the limit best runs on metric at station, the worst with best=False; figure (run, session, set) the figure name with dpi, time and the figure’s options; report (run, session) the report, with preset, station, strict. The report has one language, so lang is refused with the form that replaced it.

A bare name that a session and a run both carry is read as the session for summary, and as the run for the other values of what. runs/<name> names the run for summary.

With save the value is written to that file, by its suffix, and its path comes back; a figure is written as PNG, a report where reports go. A server always calls show with save.

Parameters:

  • ref (str | PathLike[str] | Run | Session | RunSet | Project) – A run, a session, a set of runs or a project: a path, a name in workspace ("." is the project), or the object.

  • what (Literal['summary', 'profile', 'table', 'field', 'series', 'point', 'rank', 'figure', 'report']) – What to read.

  • workspace (str | PathLike[str] | None) – The project directory, or a folder inside it.

Returns:

dict or DataFrame or Series or DataArray or Figure or Path – What what reads, or the file written with save.

Raises:

hydromodpy.core.exceptions.CommandUsageError – If what is not one the subject has; the message names those it has.

Return type:

Any
