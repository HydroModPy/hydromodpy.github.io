Exceptions and error codes#

The classes of hydromodpy.core.exceptions all derive from HydroModPyError. Each one carries a code of the form HMPY.Exxx, a one-line title(), and to_dict(), which renders the failure as a typed problem object. A few errors are defined beside the code that raises them (last section), and some calls raise built-in exceptions such as FileNotFoundError. Import the classes from the module that defines them:

from hydromodpy.core.exceptions import ConfigError

try:
    hmp.run("path/to/config.toml")
except ConfigError as err:
    print(err.code, err)   # HMPY.E100, or the code of a subclass

Catching a parent class catches its subclasses. The command line maps each class to an exit code: Exit codes. To look up a code you met, find its row in the table: HMPY.E405 is one row.
