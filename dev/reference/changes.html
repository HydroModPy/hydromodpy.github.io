What changed in the TOML#

Fields added, renamed, removed or changed between two versions. Pick the two versions below; the page opens on the newest release against this documentation. Each released version keeps a snapshot of its fields, built from its git tag, and the page compares the snapshots. Nobody writes this page: a new key, a removed key, a new default or a field moved to another profile shows up here on its own. A key shows as renamed when the new field declares its old path in renamed_from; otherwise a rename shows as one removal and one addition.

Pick a newer version on the right.
