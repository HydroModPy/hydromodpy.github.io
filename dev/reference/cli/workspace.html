hmp workspace#

$ hmp workspace [-h] <action> ...

Workspace lifecycle, project registration in the global index, and maintenance

CommandWhat it does
hmp workspace initScaffold a HydroModPy workspace (data + projects). Default: ~/hydromodpy/
hmp workspace listList the projects registered in the machine-wide global index
hmp workspace registerRegister a project in the global index (a workspace registers its projects)
hmp workspace searchFull-text search across every project registered in the global index
hmp workspace forgetUnregister a project from the global index (files stay untouched)
hmp workspace pruneDrop registrations whose project index database is missing
hmp workspace cleanRemove generated workspace artifacts

hmp workspace init#

$ hmp workspace init [-h] [--path PATH_OPT] [--force] [--project-name PROJECT_NAME] [--creator-name CREATOR_NAME] [--creator-email CREATOR_EMAIL] [path]

Scaffold a HydroModPy workspace (data + projects). Default: ~/hydromodpy/

ArgumentWhat it does
pathWorkspace path
--path PATH_OPTAlternate flag-form
--forceOverwrite an existing workspace
--project-name PROJECT_NAMEProject name written to workspace.toml, and label of the registration (default: the workspace folder name)
--creator-name CREATOR_NAMECreator name written to workspace.toml
--creator-email CREATOR_EMAILCreator e-mail written to workspace.toml

Examples

$ hmp workspace init ~/hydromodpy
$ hmp workspace init --path ./ws --project-name my_project

Exit codes it sets itself: 14. All exit codes.

hmp workspace list#

$ hmp workspace list [-h] [--json]

List the projects registered in the machine-wide global index

ArgumentWhat it does
--jsonEmit JSON instead of a table

Example

$ hmp workspace list --json

hmp workspace register#

$ hmp workspace register [-h] [--label LABEL] root_uri

Register a project in the global index (a workspace registers its projects)

ArgumentWhat it does
root_uriProject root, or workspace root to expand into the projects it holds (path or file:// URI). The directory must exist.
--label LABELOptional human-readable label

Example

$ hmp workspace register ~/hydromodpy/projects/my_project --label my_project

Exit codes it sets itself: 10 14. All exit codes.

hmp workspace search#

$ hmp workspace search [-h] [--limit LIMIT] term

Full-text search across every project registered in the global index

ArgumentWhat it does
termFree-form search term
--limit LIMITMaximum rows to print default 20

Example

$ hmp workspace search nse --limit 10

hmp workspace forget#

$ hmp workspace forget [-h] project_id

Unregister a project from the global index (files stay untouched)

ArgumentWhat it does
project_idproject_id returned by 'hmp workspace list'

Example

$ hmp workspace forget 3f2a9c1e

hmp workspace prune#

$ hmp workspace prune [-h]

Drop registrations whose project index database is missing

Example

$ hmp workspace prune

hmp workspace clean#

$ hmp workspace clean [-h] [--workspace WORKSPACE] [--all] [--results] [--data-cache] [--runtime] [--share] [--scratch] [--figures] [--dry-run] [-y]

Remove generated workspace artifacts

ArgumentWhat it does
--allClean every group below
--resultsThe index database and the runs/ tree
--data-cacheThe data cache
--runtimeThe .hmp/ runtime folder
--shareThe published share/ tree
--scratchThe scratch folders (.hmp/scratch)
--figuresThe share/figures folders of the projects
--dry-runList what would be removed and remove nothing (the default unless -y is given)
-y, --yesDelete without dry-run

Also takes the shared options --workspace.

Examples

$ hmp workspace clean --results --dry-run
$ hmp workspace clean --all -y

Exit codes it sets itself: 10 14. All exit codes.
