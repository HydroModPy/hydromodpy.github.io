Exit codes#

A command ends with the code of its outcome. Codes 0, 1 and 2 keep their usual meaning, 130 is the POSIX code of an interrupted process, and the codes from 10 name the category of the failure. An exception that a command does not catch ends with the code of its class: Exceptions and error codes lists the classes and their HMPY.Exxx codes.
