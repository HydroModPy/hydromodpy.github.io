hmp catalog#

$ hmp catalog [-h] <action> ...

Inspect, query, and maintain workspace catalogs

CommandWhat it does
hmp catalog lsList simulations recorded in a workspace catalog
hmp catalog queryRun a SQL statement against the project index database
hmp catalog showShow simulation metadata, metrics, parameters, and storage layout
hmp catalog pointRead a variable in one cell of a finished run (coordinates, cell id, or depth)
hmp catalog gcMaintenance: apply the retention policy, expire trash, quarantine orphan stores, replay purges, compact DuckDB + Zarr
hmp catalog reindexRebuild the project index from what the run directories declare
hmp catalog deleteMove a simulation to the trash (reversible); --now to purge permanently
hmp catalog restoreRestore a trashed simulation (auto-versions if the name was reused)
hmp catalog trashList trashed runs, or permanently empty the trash with --empty
hmp catalog tagAdd or remove tags on a simulation (reserved tag: pinned)
hmp catalog noteAppend a timestamped note to a simulation
hmp catalog renameRename a run: its directory under runs/ is moved, then the index is updated
hmp catalog diffCompare two runs' parameters and outlet metrics
hmp catalog watchShow running simulations with heartbeat age and staleness
hmp catalog importImport a .hmp archive into the workspace (checksums verified first)
hmp catalog rerunRe-launch a run from its config snapshot with --set path=value overrides

hmp catalog ls#

$ hmp catalog ls [-h] [-w WORKSPACE] [--format {table,json,csv}] [--verbosity {quiet,normal,verbose,debug} | -q | -v | --debug] [--project PROJECT] [--solver SOLVER] [--catchment CATCHMENT] [--status STATUS] [--tag TAG] [--limit LIMIT]

List simulations recorded in a workspace catalog

ArgumentWhat it does
--project PROJECTRestrict to one project (looks at projects/<name>/.hmp/index.duckdb)
--solver SOLVERFilter by solver (exact match; aliases: mf6 -> modflow6, nwt -> modflow_nwt)
--catchment CATCHMENTFilter by study area name (substring match)
--status STATUSFilter by status (completed, running, failed, trashed, ...)
--tag TAGFilter by an exact tag (e.g. pinned)
--limit LIMITMaximum number of rows to print

Also takes the shared options --workspace --format --verbosity --quiet --verbose --debug.

Example

$ hmp catalog ls --solver mf6 --format json

Exit codes it sets itself: 10 14. All exit codes.

hmp catalog point#

$ hmp catalog point [-h] [-w WORKSPACE] [--format {table,json,csv}] [--verbosity {quiet,normal,verbose,debug} | -q | -v | --debug] --var NAME (--xy X Y | --cell CELL) [--layer LAYER | --depth METRES] [--label LABEL] [--timestep TIMESTEP] [-o FILE] SIM_REF [SIM_REF ...]

Read a variable in one cell of a finished run (coordinates, cell id, or depth)

ArgumentWhat it does
SIM_REFOne or more runs (full sim_id, unique hex prefix, name, or an @-selector). Several runs stack their answers for comparison.
--var NAMEField to read, persisted or virtual. Repeat for several fields. required
--xy X YCoordinates in the simulation CRS
--cell CELLZero-based cell index
--layer LAYERZero-based layer index
--depth METRESDepth below the local model top; picks the layer
--label LABELName of the point reported in the table
--timestep TIMESTEPKeep a single timestep (negative counts from the end)
-o, --output FILEWrite the table to a .csv or .parquet file

Also takes the shared options --workspace --format --verbosity --quiet --verbose --debug.

Examples

$ hmp catalog point @last --var head --xy 395100 6824925
$ hmp catalog point @last --var head --cell 5000 --timestep -1
$ hmp catalog point @last --var head --xy 395100 6824925 --depth 12.5
$ hmp catalog point run_a run_b --var watertable_depth --cell 5000 -o point.csv

Exit codes it sets itself: 10 14. An exception it does not catch ends with the code of its class. All exit codes.

hmp catalog gc#

$ hmp catalog gc [-h] [--format {table,json,csv}] [--verbosity {quiet,normal,verbose,debug} | -q | -v | --debug] [-w WORKSPACE] [--apply] [--keep-versions N|all] [--max-age-days DAYS] [--purge-figures]

Maintenance: apply the retention policy, expire trash, quarantine orphan stores, replay purges, compact DuckDB + Zarr

ArgumentWhat it does
--applyExecute the plan and free resources (default: print the plan only)
--keep-versions N|allVersions kept per run lineage; older ones go to the trash (default: 5, 'all' disables the rule)
--max-age-days DAYSAlso trash runs created more than DAYS ago (default: no age limit)
--purge-figuresAlso quarantine the regenerable figures/ directory of each run

Also takes the shared options --format --verbosity --quiet --verbose --debug --workspace.

A run tagged 'pinned' is exempt from every retention rule.

Examples

$ hmp catalog gc
$ hmp catalog gc --keep-versions 3 --max-age-days 180 --apply

Exit codes it sets itself: 10 14. All exit codes.

hmp catalog reindex#

$ hmp catalog reindex [-h] [-w WORKSPACE] [--format {table,json,csv}] [--verbosity {quiet,normal,verbose,debug} | -q | -v | --debug]

Read every sealed run under runs/ and every calibration session under sessions/, and rebuild .hmp/index.duckdb from them. The current index stays readable until the new one is published in one atomic step, and rebuilding twice yields the same index. What no run directory carries is not rebuilt, and is lost: the audit log and its hash chain (a fresh chain starts), the deletion tombstones, the export log, the workflow journal and its event stream (an interrupted run can no longer be resumed), and the observation series with their stations (re-ingested by the next run from the data files the config declares).

Also takes the shared options --workspace --format --verbosity --quiet --verbose --debug.

Example

$ hmp catalog reindex

Exit codes it sets itself: 14. An exception it does not catch ends with the code of its class. All exit codes.

hmp catalog rename#

$ hmp catalog rename [-h] [-w WORKSPACE] [--verbosity {quiet,normal,verbose,debug} | -q | -v | --debug] SIM_REF new_name

Rename a run: its directory under runs/ is moved, then the index is updated

ArgumentWhat it does
SIM_REFFull sim_id, unique hex prefix, name, or an @-selector (@last, @best:METRIC, @worst:METRIC, @running)
new_nameNew simulation name

Also takes the shared options --workspace --verbosity --quiet --verbose --debug.

The run directory is named after the run, so a rename moves runs/<old>/ to runs/<new>/ before updating the index. The new name must be free: a collision with a live run is refused.

Example

$ hmp catalog rename ab12cd34 final_run

Exit codes it sets itself: 10 14. An exception it does not catch ends with the code of its class. All exit codes.
