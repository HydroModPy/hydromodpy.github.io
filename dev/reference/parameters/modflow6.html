# ims_print_option = "NONE"IMS PRINT_OPTION. expert
Path
modflow6.runtime.ims_print_option
More

'SUMMARY' adds one line per time step to the listing with the outer and inner iteration counts, which is the only way to tell an expensive iteration from too many of them. Deliberately NOT tied to mf_verbose: that switch also sets print_input and print_flows on the whole model, and on a run with one drain per cell those print every boundary flux at every step. 'NONE' by default; 'SUMMARY' costs a line per step.

Values
  • "NONE"
  • "SUMMARY"
  • "ALL" no explanation
Accepted
"NONE" | "SUMMARY" | "ALL"
# print_head = falseRe-print the whole head field, formatted as text, into the model listing at every output step. expert
Path
modflow6.runtime.print_head
More

Nothing in the package reads it, and the binary head file already carries the same numbers. It costs DISK, not time: measured on the Nancon at 25 m, 243 552 cells over 1826 daily steps wrote a 2.96 GB listing, but a one-variable-at-a-time probe put its effect on the solve at -0.4 per cent, inside the noise. Default false to stop producing the file, not to go faster. The listing keeps its budget summaries and its convergence reports either way, and Mf6ListBudget reads those.

Accepted
true | false
# save_specific_discharge = trueCompute and write the cell-by-cell Darcy velocity (DATA-SPDIS). expert
Path
modflow6.runtime.save_specific_discharge
More

Required by particle tracking and by any velocity figure. The cost is the COMPUTATION, not the write: MODFLOW interpolates a velocity vector per cell at every step. Measured on the Nancon at 25 m by changing this switch alone, 4.64 -> 3.68 s per step, 20.7 per cent of the solve. A calibration that only scores a discharge series should turn it off.

Accepted
true | false
# save_saturation = trueCompute and write the cell saturation (DATA-SAT). expert
Path
modflow6.runtime.save_saturation
More

Measured on the Nancon at 25 m by changing this switch alone, 4.64 -> 4.13 s per step, 10.9 per cent of the solve. Same reasoning as save_specific_discharge: the cost is the per-cell computation, and the two together are worth 34.5 per cent.

Accepted
true | false

# mf6_newton = trueEnable the MODFLOW 6 Newton-Raphson formulation. expert
Path
modflow6.runtime.mf6_newton
More

Catchment cells are always convertible (unconfined), so Newton with under-relaxation is the robust default. Unlike MODFLOW-NWT, it builds the horizontal conductance from the full cell thickness times the upstream saturation. The grid MODFLOW 6 reads therefore has a computational top that gives every cell of the top layer the same thickness, so that this conductance is the one of NWT; the ground stays in every package and in the run store.

Accepted
true | false

# mf6_ats = falseEnable MODFLOW 6 adaptive time stepping (ATS) on transient periods. expert
Path
modflow6.runtime.mf6_ats
More

Each period starts at the step simulation.time.substeps_per_period asked for and MF6 subdivides below it only where the solver cannot converge (e.g. littoral wet/dry under Newton); it never grows past that step, so turning ATS on cannot coarsen a run. When on, OC saves per period end so the extraction still sees one record per period. Default off (baseline).

true | false
