[modflownwt.sgrid.top_sampling]#

How the top of the solver grid is sampled from the DEM.

Connections found in the code (1)
  • Same name [modflow6.sgrid.top_sampling] How the top of the solver grid is sampled from the DEM. mode = "centroid" | "zonal"
[modflownwt.sgrid.top_sampling]
# mode = "centroid"Top-sampling strategy.
Path
modflownwt.sgrid.top_sampling.mode
More

'centroid' samples the DEM at each cell generator, or resamples it to a structured grid (fast, the current behaviour, byte-identical default). 'zonal' reduces every DEM pixel inside a cell with per-class stats.

Values
  • "centroid"
  • "zonal"
Accepted
"centroid" | "zonal"
# hillslope_stat = "median"Zonal statistic over non-channel (hillslope) pixels inside a cell.
Path
modflownwt.sgrid.top_sampling.hillslope_stat
Values
  • "mean" : Averages every hillslope pixel in the cell to set its top elevation.
  • "median" : Uses the median hillslope pixel elevation, robust to outlier pixels.
  • "min" : Uses the lowest hillslope pixel elevation found inside the cell.
  • "max" : Uses the highest hillslope pixel elevation found inside the cell.
  • "p10" : Uses the 10th percentile of hillslope pixel elevations inside the cell.
  • "p25" : Uses the 25th percentile of hillslope pixel elevations inside the cell.
Accepted
"mean" | "median" | "min" | "max" | "p10" | "p25"
# channel_stat = "min"Zonal statistic over channel pixels inside a cell (thalweg-preserving; 'min' keeps the incised low).
Path
modflownwt.sgrid.top_sampling.channel_stat
Values
  • "min" : Uses the lowest channel pixel elevation, keeping the incised thalweg low.
  • "p10" : Uses the 10th percentile of channel pixel elevations, near the thalweg low.
  • "p25" : Uses the 25th percentile of channel pixel elevations, above the thalweg low.
  • "median" : Uses the median channel pixel elevation, less aggressive than the thalweg low.
  • "mean" : Averages channel pixel elevations, smoothing over the incised thalweg.
Accepted
"min" | "p10" | "p25" | "median" | "mean"
