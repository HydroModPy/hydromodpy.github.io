transport.modflow6prt.parameters.release_zone release_zone “domain” Cells particles are released from: ‘domain’ (every active cell), ‘domain_nonriver’ (the same without river cells), ‘upstream’ (the highest cells), ‘upstream_nonriver’, ‘river’, ‘outlet’ (the lowest cells), or ‘custom’ (the cells particle_cell_ids lists). transport.modflow6prt.parameters.upstream_top_quantile upstream_top_quantile 0.9 - Top-elevation quantile used by upstream release zones. A value of 0.90 selects cells in the highest 10 percent of active cell-top elevations. transport.modflow6prt.parameters.outlet_bottom_quantile outlet_bottom_quantile 0.1 - Bottom-elevation quantile used by the ‘outlet’ release zone. A value of 0.10 selects cells in the lowest 10 percent of active cell-top elevations. transport.modflow6prt.parameters.track_dir track_dir “forward” forward Direction particles are tracked in. MODFLOW 6 PRT tracks with the flow only, so ‘forward’ is the one value. transport.modflow6prt.parameters.porosity porosity not set - Effective (total) porosity [-] for particle tracking (v = q / porosity). When omitted, the flow model specific yield is used where positive, with a warning, since specific yield underestimates pore volume. transport.modflow6prt.parameters.local_z local_z 0.5 - Height of the release point inside its cell, from 0 at the bottom to 1 at the top. transport.modflow6prt.parameters.particle_cell_ids particle_cell_ids not set Cells to release particles from, by their index in the mesh counted from 0. transport.modflow6prt.parameters.max_particles max_particles not set - Most release cells kept after the zone is selected; the kept cells are spread over the zone. Unset, every cell of the zone releases. A count. transport.modflow6prt.parameters.sel_slice sel_slice not set - Keep one release cell out of this many, in cell order, before max_particles applies. A count. transport.modflow6prt.parameters.release_times_days release_times_days not set day Times particles are released at, in days from the start of the run. Unset, they are released once at the start. transport.modflow6prt.parameters.track_times_days track_times_days not set day Times the particle positions are written at, in days from the start of the run. transport.modflow6prt.parameters.track_time_step_days track_time_step_days not set day Spacing, in days, of regular output times from 0 to stop_time_days. track_times_days wins when it is given. It needs stop_time_days. transport.modflow6prt.parameters.stop_time_days stop_time_days not set day Time all particles stop at, in days from the start of the run. transport.modflow6prt.parameters.stop_travel_time_days stop_travel_time_days not set day Longest time a particle may travel, in days from its release. transport.modflow6prt.parameters.extend_tracking extend_tracking true Keep tracking particles after the last flow time step, with the last flow field, when MODFLOW 6 allows it. transport.modflow6prt.parameters.dry_tracking_method dry_tracking_method “drop” drop stop stay MF6 PRT behavior for dry-but-active cells. transport.modflow6prt.parameters.exit_solve_tolerance exit_solve_tolerance 1e-05 PRT generalized Pollock exit solve tolerance. Matches the MF6 prt-prp.dfn default (1e-5), which works well for many problems. transport.modflow6prt.parameters.write_track_csv write_track_csv true Write the particle track CSV file. HydroModPy reads the tracks from it, so turning it off leaves the run with no particle result. transport.modflow6prt.parameters.write_track_binary write_track_binary true Write the binary particle track file of MODFLOW 6 as well.
