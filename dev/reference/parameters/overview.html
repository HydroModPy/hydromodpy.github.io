[overview]#

Overview report settings (watershed identity card).

  • overview [table] · optional · 14 user keys
  • Start a file: hmp config template --modules overview (download it), then hmp config check file.toml. Minimal file
[overview]
# name = ""Name of the watershed shown in the titles of the report.
Path
overview.name
More

Unset, the catchment name of the workspace is used.

Accepted
string
# date_start = "2019-01-01"Start of the overview window (ISO date, e.g. '2019-01-01'). example value
Path
overview.date_start
More

Overview mode has no [simulation.time], so this is the date declaration every [data.<type>] section without a window of its own inherits. Must be declared together with date_end.

Accepted
string
Example
"2019-01-01"
# date_end = "2025-12-31"End of the overview window (ISO date, e.g. '2025-12-31'). example value
Path
overview.date_end
More

Overview mode has no [simulation.time], so this is the date declaration every [data.<type>] section without a window of its own inherits. Must be declared together with date_start.

Accepted
string
Example
"2025-12-31"
