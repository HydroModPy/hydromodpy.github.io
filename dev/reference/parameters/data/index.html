[data]#

Top-level [data] configuration for the data variables.

  • data [table] · optional · 303 user keys, 136 dev or expert
  • Start a file: hmp config template --modules data (download it), then hmp check file.toml. Minimal file
Connections found in the code (1)
  • The code says flow.sinks_sources.recharge.soil: [flow.sinks_sources.recharge.soil] computes the recharge from the precipitation and the ETP, and data.types also loads one from [data.recharge]: the model would receive one and ignore the other. Remove "recharge" from data.types to keep the soil reservoir (and write recharge__delete = true under [data] if a base file declares it), or remove [flow.sinks_sources.recharge.soil] to use the loaded rech
