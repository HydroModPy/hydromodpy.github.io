[data.geology]#

Top-level geology variable configuration.

  • data.geology [table] · optional · 7 user keys, 6 dev or expert
Connections found in the code (4)
  • Read when data.types lists "geology".
  • Same name [mesh_catchment.geology] Geology polygons the mesh follows. kind = "auto" | "raster" | "vector"
  • Same name [site_selection.criteria.geology] Geology criterion configuration. mode = "hard_reject" | "warning" | "score" | "stratify" | "report_only"
  • Same name [context.geology] Geological map the legend table is read from.

[[data.geology.sources]]#

At least one geology data source.

Repeat the table: one [[data.geology.sources]] block per item.

source selects the shape of this table. One tab per shape, the default first.
