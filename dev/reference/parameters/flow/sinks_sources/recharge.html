[flow.sinks_sources.recharge]#

Typed payload for diffuse recharge over the model domain.

  • flow.sinks_sources.recharge [table] · optional · 12 user keys, 5 dev or expert
Connections found in the code (2)

  • Same name [data.recharge] Recharge configuration (drainage / soil infiltration time series). Read when data.types lists "recharge". source = "custom" | "sim2" | "synthetic"

# first_clim = "mean"Recharge rate of every steady stress period: every period of a steady run, and the first period of a transient run when flow.first_period_steady is true. dev
Path
flow.sinks_sources.recharge.first_clim
More

'mean' is the mean of the per-period rates, one weight per period; 'first' is the rate of period 0; a number is that rate, in the units of values. A transient period keeps its own rate. The same rule holds for one value per period and for one grid per period, under every solver. With negative_to_evt, the steady period takes the rule on the recharge part and on the deficit part, so its net rate is the one stated here.

See
flow.first_period_steady
Accepted
string or number
Example
"mean", "first", 2.0

[flow.sinks_sources.recharge.soil]#

Daily soil reservoir that turns precipitation and ETP into recharge.

[flow.sinks_sources.recharge.soil]
ru = "150 mm"Available water capacity of the soil, in mm of water: what the roots can draw between field capacity and wilting point. required mm [0, 1000] calibrable example value
Path
flow.sinks_sources.recharge.soil.ru
More

A bare number is in mm; "120 mm" and "12 cm" also read. Between 0 and 1000 mm. Required, since it belongs to the site. In doubt, start from 150 mm and compare the recharge the soil alone prints for 50 to 250 mm with the gauged discharge (hmp run <file> --until load_data). With [data.soil_capacity], it is the mean capacity of the SAFRAN cells, and the raster spreads it over classes inside each cell. Calibrate it with [calibration.parameters.ru].

Accepted
number or "<n> mm" (a bare number is read in the canonical unit)
Valid range
[0, 1000] (refused outside)
Unit
mm
Example
"150 mm"
Calibration
yes, search space identity, prior uniform, bounds belong to the site: write them in calibration.parameters.<name>.bounds
# alpha = 0.6Share of ru above which the soil evaporates at the full rate kc x ETP. ]0, 1] calibrable
Path
flow.sinks_sources.recharge.soil.alpha
More

Below alpha x ru, ETR falls linearly with the stored water. It is 1 - p of FAO-56 and LP of HBV. Above 0, at most 1. Kept fixed by default: the discharge alone hardly constrains it.

The rain that falls on it runs off at once, with no infiltration and no evaporation, and reaches the streams, the lakes and the gauged discharge. The soil reservoir covers the rest of the area. From 0 up to, not including, 1. Calibrate it with [calibration.parameters.impervious_fraction]; the range belongs to the site, so a file has to state it.

# transit_time = 0.0Mean time the water leaving the soil takes to cross the unsaturated zone down to the water table, in days. day [0, 30] calibrable

flow.sinks_sources.recharge.soil.transit_time

A linear reservoir with this time constant delays and smooths the recharge; 0 sends it the same day. A bare number is in days; "5 days" also reads. At most 30 days: a longer delay would rebuild the slow groundwater memory MODFLOW computes itself.

# curve_number = ‹number›SCS curve number (AMC II), dimensionless, of a HELP-style surface runoff (Schroeder et al. 1994): the unsealed share of the rain above a daily retention loses some to a fast runoff, more as the soil is wetter. [30, 98] calibrable
Path

# runoff_lag = 0.0Pure delay applied to the routed curve-number runoff, after runoff_time, before it reaches the gauged discharge: the travel time to the outlet plus any lag between the forcing's daily step and the gauge's. day [0, 5] calibrable
Path
flow.sinks_sources.recharge.soil.runoff_lag
More

Read only when curve_number is set. 0 adds no delay, bit for bit as before; "0.75 days" also reads, interpolated linearly between the neighbouring whole-day shifts. Between 0 and 5 days: a longer shift belongs to runoff_time's reservoir, not to a fixed travel time. Calibrate it with [calibration.parameters.runoff_lag].

Accepted
number or "<n> day" (a bare number is read in the canonical unit)
Valid range
[0, 5] (refused outside)

day

# spinup = "first_year"State of the soil on the first day.
Path
flow.sinks_sources.recharge.soil.spinup
More

"first_year" repeats the first 365 days of the run until the storage at the end of that year moves by less than 0.1 mm, 20 times at most; the run must last one year at least. "none" starts from a full soil, the state of a soil in a wet winter.

Values
  • "first_year" : Repeat the first year until the soil storage settles.
  • "none" : Start from a full soil and an empty transit store.
Accepted
"first_year" | "none"
