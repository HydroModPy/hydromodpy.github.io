[flow.sinks_sources.etp]#

Typed payload for diffuse evapotranspiration over the model domain.

  • flow.sinks_sources.etp [table] · optional · 2 user keys, 6 dev or expert
Connections found in the code (2)
  • Read when flow.active_sinks_sources lists "etp".
  • Same name [data.etp] ETP configuration (potential evapotranspiration). Read when data.types lists "etp". source = "custom" | "sim2" | "explore2"
[flow.sinks_sources.etp]
# values = 0.0Evapotranspiration rate, in the unit that units names (mm/day by default): one number, one number per stress period, a table {period: value}, or the series loaded from [data.etp].
Path
flow.sinks_sources.etp.values
More

Values must not be negative: the EVT package takes them as outflow rates.

See
data.etp
Accepted
any value
# extinction_depth = 1.0Depth (m) below the EVT surface where the water table stops evaporating; the rate falls linearly between the surface and this depth. m > 0 calibrable
Path
flow.sinks_sources.etp.extinction_depth
More

1 m by default. Read by MODFLOW-NWT, and by MODFLOW 6 in soil mode for the ETP the soil left unmet. Calibrate it with [calibration.parameters.extinction_depth]; the range belongs to the site, so a file has to state it.

Accepted
number or "<n> m" (a bare number is read in the canonical unit)
Valid range
> 0 (refused outside)
Unit
m
Calibration
yes, search space identity, prior uniform, bounds belong to the site: write them in calibration.parameters.<name>.bounds
# heterogeneous_source = ‹any value›Optional raw data source for heterogeneous (2D per-cell) ETP. dev
Path
flow.sinks_sources.etp.heterogeneous_source
More

When set, the solver adapter discretizes FieldRecords onto the MODFLOW grid instead of using the scalar 'values' field. Expected: LoadResult with FieldRecords.

Accepted
any value
# first_clim = "mean"ETP rate of every steady stress period, read by MODFLOW-NWT: every period of a steady run, and the first period of a transient run when flow.first_period_steady is true. dev
Path
flow.sinks_sources.etp.first_clim
More

'mean' is the mean of the per-period rates, one weight per period; 'first' is the rate of period 0; a number is that rate. A transient period keeps its own rate.

See
flow.first_period_steady
Accepted
string or number
Example
"mean", "first", 2.0
# units = "mm/day"Units of the ETP data source. dev
Path
flow.sinks_sources.etp.units
More

Data-manager outputs use mm/day by convention; converted to m/s at runtime.

Accepted
string
# surface_offset = 2.0Distance (m) the EVT surface sits below its reference. m >= 0 dev
Path
flow.sinks_sources.etp.surface_offset
More

Under MODFLOW-NWT the reference is the topographic surface and the default is 2 m. In soil mode under MODFLOW 6 the reference is the drain elevation of the cell (the top, or the top minus half of solver.drain_band_depth_m) and the default is 0 m, since the soil reservoir has already taken the ETP it could.

Accepted
number or "<n> m" (a bare number is read in the canonical unit)
