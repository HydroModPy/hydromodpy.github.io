Connections found in the code (2)
  • The code says domain.depth_model: A constant head is below the bottom of its cell, and MODFLOW 6 stops on it. Raise the head above the bottom of the aquifer there, give the boundary a deeper aquifer (domain.depth_model), or remove it from flow.active_bc.

# runtime_backend = "auto"Engine the Boussinesq solver uses for its nonlinear solve. experimental
Path
flow.runtime_backend
More

'local' and 'scipy' build a dense matrix and run on at most 400 cells; 'scipy_sparse' and 'petsc' (it needs petsc4py) have no such limit. 'auto' runs 'local' up to 400 cells and 'scipy_sparse' above, and logs the choice. The MODFLOW solvers do not read it.

Values
  • "auto"
  • "local"
  • "scipy"
  • "scipy_sparse"
  • "petsc"
Accepted
"auto" | "local" | "scipy" | "scipy_sparse" | "petsc"
Example
"auto", "scipy_sparse"
# partition_release_depth_m = 0.05Depth scale, in metres, of the regularized partition, the surface closure the Boussinesq solver uses by default on every engine but petsc. m > 0
Path
flow.partition_release_depth_m
More

A cell whose water table lies d metres below the land surface releases at the surface the share exp(-d / depth) of the water it receives, its lateral inflow plus its recharge and wells: all of it with the water table at the surface, 37 % at one depth scale, 2e-9 at 1 m with the default 0.05 m. It stands for the microtopography over which seepage starts, and smooths the onset of seepage for the Newton solve. A smaller value comes closer to the exact threshold of the complementarity closure and makes the solve stiffer. The other closures and the MODFLOW solvers do not read it.

Accepted
number
Valid range
> 0 (refused outside)
Unit
m
Example
0.05, 0.02

# active_sinks_sources = []Explicitly activated sink/source names for this flow run: 'recharge', 'wells', 'etp'.
Path
flow.active_sinks_sources
More

'etp' means three things. Under MODFLOW-NWT the loaded ETP drives the EVT package. Under MODFLOW 6 it acts only in soil mode ([flow.sinks_sources.recharge.soil]), where it sends the ETP the soil left unmet to the EVT package; outside soil mode MODFLOW 6 ignores it and says so. Boussinesq rejects it at solver-contract validation. An empty list means no sink/source package is assembled by the solver.

Accepted
list of string
Example
["recharge"], ["recharge", "wells"], ["etp"]

# restart_from = ‹string›Optional hotstart: path to a prior simulation Zarr store whose last time step seeds the initial heads (and the lake stage), overriding [flow.ic].
Path
flow.restart_from
More

The prior run must share this run's mesh, so enable [mesh_catchment] cache = true; otherwise the cell count differs and restart is refused. None keeps [flow.ic]. Read only by a solver that declares it can: elsewhere the run is refused rather than started from [flow.ic] without a word. This is one of the four ways to say where a transient starts, next to [flow.ic] type='steady_state' (equilibrium under the mean recharge, or under a rate you state with source='prescribed'), type='custom'/'top'/'bottom' (a level you write), and hmp spinup (repeat a representative window until the state stops moving, then point this key at its result).

See
flow.ic
Accepted
