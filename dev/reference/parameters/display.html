[display]#

Display behaviour resolved from the [display] TOML section.

  • display [table] · optional · 10 user keys, 2 dev or expert
  • Start a file: hmp config template --modules display (download it), then hmp config check file.toml. Minimal file
[display]
# enabled = trueMaster switch.
Path
display.enabled
More

When False, no figure is rendered or saved.

Accepted
true | false
# preset = "default"Named theme applied before rendering any figure.
Path
display.preset
Values
  • "default" : Uses a colorful sans-serif palette on a white background, for screen viewing.
  • "print" : Uses a grayscale serif palette sized for black-and-white print output.
  • "dark" : Uses a bright palette on a dark background, for dark-themed displays.
Accepted
"default" | "print" | "dark"
# show = falseOpen an interactive window via matplotlib.pyplot.show.
Path
display.show
Accepted
true | false
# save = trueWrite rendered figures to disk under output_dir.
Path
display.save
Accepted
true | false
# output_dir = "figures"Name of the figures directory inside the run directory (<project>/runs/<run>/<output_dir>/).
Path
display.output_dir
More

Declared as a name, not a path, so it stays anchored to the run it describes.

Accepted
string
# cmap = "viridis"Force ONE colormap onto every spatial figure.
Path
display.cmap
More

Writing it at all is the decision, not the value: each figure otherwise picks a scale suited to what it shows, reversed for a depth, diverging for a difference, discrete for an indicator, and this replaces all of them. Writing the default spelled out is therefore NOT a no-op, unlike everywhere else. Leave it out unless one scale for everything is what you want.

Accepted
string
# figures = []Names of registered figures to auto-render at the end of hmp run (and consumed by hmp viz gallery).
Path
display.figures
More

Every name must exist in the figure registry; list them with hmp viz list. A figure whose requirements the run does not meet is skipped with an explicit reason. Empty list disables auto-rendering. Disable per-run via hmp run --no-display or for an entire Python Project via Project(..., no_display=True).

Accepted
list of string
# on_error = "warn"Behaviour when a figure that IS applicable fails while rendering.
Path
display.on_error
More

'warn' logs and continues (default, keeps a long run alive); 'raise' propagates, which is what example and CI configs want so a broken figure cannot pass unnoticed.

Values
  • "warn"
  • "raise"
Accepted
"warn" | "raise"
# time = ‹string or integer›The instant every figure that draws one instant shows: a date ("2002-10-15"), "first" or "last".
Path
display.time
More

Each such figure draws the stress period that holds the date, so the same date names the same month on a monthly, a daily or a one-period steady run. A time in [display.overrides.<figure>] wins over it. Unset, each figure picks its own instant: the last period, or for the stream-network maps the state their calibration criterion read. A date outside a run skips the figure with the reason.

Accepted
string or integer
# overrides = {}Per-figure options, keyed by figure name (e.g. {'piezometric_map': {'cmap': 'cividis', 'vmin': 0}}).
Path
display.overrides
More

A key the figure does not take is refused at load, with the list of the keys it takes. A figure that draws one instant takes time.

Accepted
table { key = dict }
# backend = "auto"Matplotlib backend. dev
Path
display.backend
More

'auto' selects Agg in headless mode and a GUI backend when show is enabled.

Values
  • "agg" no explanation
  • "qt5agg" no explanation
  • "auto"
Accepted
"agg" | "qt5agg" | "auto"
# dpi = 150DPI used when saving raster figures. >= 1 dev
Path
display.dpi
Accepted
integer
Valid range
>= 1 (refused outside)
