[calibration.parameters]#

User declaration for one calibrated parameter.

  • calibration.parameters { name = table } · optional · 7 user keys

One table per name you choose: [calibration.parameters.<name>]. The name is free text.

[calibration.parameters.<name>]
# bounds = ‹list of number›[low, high] physical bounds, in the unit the target declares. exactly 2 items
Path
calibration.parameters.<name>.bounds
More

Falls back to what the field annotates when the file omits it, which most fields deliberately leave unset because a range belongs to the site.

Accepted
list of number
Valid range
exactly 2 items (refused outside)
# transform = "identity"Transform applied before sampling.
Path
calibration.parameters.<name>.transform
More

'log' for strictly-positive quantities spanning orders of magnitude. Unset, the target's own field decides: a hydraulic conductivity declares 'log' where it is defined, so a file states this only to depart from it.

Values
  • "identity" : Searches the value as written.
  • "log" : Searches the logarithm of the value: for a positive quantity that spans orders of magnitude.
  • "logit" : Searches log(x / (1 - x)): for a share strictly between 0 and 1. Both bounds must lie inside (0, 1).
Accepted
"identity" | "log" | "logit"
# prior = "uniform"Distribution, between the bounds, that starting points, random draws and Bayesian samplers take values from.
Path
calibration.parameters.<name>.prior
Values
  • "uniform" : Every value between the bounds is equally likely.
  • "log_uniform" : Every decade between the bounds is equally likely.
  • "normal" : A normal law centred between the bounds, with a standard deviation of a sixth of their span, cut at the bounds.
Accepted
"uniform" | "log_uniform" | "normal"
# path = ‹string›Dotted TOML path of the value to move, such as 'flow.param.K.field.value'.
Path
calibration.parameters.<name>.path
More

Optional, and the way out rather than the way in: when omitted, the section name is resolved against the project catalogue ('hmp config targets' lists it). Write one to reach a value the catalogue does not carry, or to settle a name two targets answer to. A path written here wins without a lookup, and a parameter that writes one inherits nothing from the field it points at.

Accepted
string
# target = ‹string›Readable alias for 'path'.
Path
calibration.parameters.<name>.target
More

When both are set, 'target' wins.

Accepted
string
# mode = "replace"'replace' writes the sampled value as-is; 'scale' multiplies the base TOML value at the target path by the sample.
Path
calibration.parameters.<name>.mode
Values
  • "replace"
  • "scale"
Accepted
"replace" | "scale"
# units = "m/s"Unit the bounds are written in, such as 'm/s'. example value
Path
calibration.parameters.<name>.units
More

The bounds are checked against the physical range of the target in this unit. Unset, the unit the target declares applies.

Accepted
string
Example
"m/s"
