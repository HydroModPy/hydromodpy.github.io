TOML parameters#

Every section of the configuration file, generated from the models. Each page reads like the file you write: one block per table, the keys you must write first, optional keys commented with their default, developer and expert keys behind a switch, one tab per shape when a table has several. Click a line for its card.

Two commands go from a block to a verdict:

hmp config template --modules flow > flow.toml   # the keys of one section
hmp config check my_run.toml                     # validate a file
