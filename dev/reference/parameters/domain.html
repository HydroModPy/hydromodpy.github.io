# zone_ids = []Zone identifiers Domain.set_zone is allowed to register.
Path
domain.zone_ids
More

It is an allowlist, not a request: nothing here causes a zone to be built. 'catchment' and 'geology' are appended by HydroModPy because the binders write under those fixed names, and every support id is appended too, so what belongs here is a project's own zonations. Order is never read. Spatial-support declarations live under domain.supports.

Accepted

[domain.supports.<name>]#

One table per name you choose: [domain.supports.<name>]. The name is free text.

kind selects the shape of this table. One tab per shape, the default first.

[domain.depth_model]#

Vertical domain model configuration.

Connections found in the code (2)
  • The code says flow.active_bc: A constant head is below the bottom of its cell, and MODFLOW 6 stops on it. Raise the head above the bottom of the aquifer there, give the boundary a deeper aquifer (domain.depth_model), or remove it from flow.active_bc.
  • The code says data.substratum: domain.depth_model kind = ... reads the raster declared under [data.substratum], and the configuration declares none.

kind selects the shape of this table. One tab per shape, the default first.
