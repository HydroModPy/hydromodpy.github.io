[site_selection.territory]#

Spatial domain where candidate basins are searched.

  • site_selection.territory [table] · required in every file · 7 user keys
[site_selection.territory]
# mode = "bbox"How the search territory is given: by administrative regions, by departments, by a polygon file or by a bounding box.
Path
site_selection.territory.mode
More

Each mode reads its own key.

Values
  • "admin_regions" : Bounds the territory to the bounding box of the named administrative regions.
  • "admin_departments" : Bounds the territory to the bounding box of the named departments.
  • "polygon_file" : Bounds the territory to the bounding box of a user-supplied polygon file.
  • "bbox" : Bounds the territory to an explicit xmin, ymin, xmax, ymax box.
Accepted
"admin_regions" | "admin_departments" | "polygon_file" | "bbox"
# country = ‹string›Country code used by administrative territory modes.
Path

Accepted
