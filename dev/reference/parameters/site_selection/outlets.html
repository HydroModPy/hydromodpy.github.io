[site_selection.outlets]
# candidate_mode = "network_sampling"How candidate outlets are generated: sampled on the DEM stream network, or taken at the observation stations.
Path
site_selection.outlets.candidate_mode
Values
  • "network_sampling" : Generates candidate outlets by sampling the DEM-derived stream network.
  • "station_outlets" : Uses imported observation station locations, such as flow stations, as candidate outlets.
Accepted
"network_sampling" | "station_outlets"
