The whole file as a tree#

Type a few words: every word must match, and a key whose name matches comes first.

    • [workflow] 3 Workflow configuration.
      • Open the page of [workflow]
      • mode = ‹"simulation" | "calibration" | "overview" | "comparison" | "testbed" | "site_selection"› requiredWorkflow mode dispatched by hmp run.
      • verbosity = "normal" How much the run prints on the console.
      • profile = false Profile the run with pyinstrument (honored by the hmp CLI; the --profile flag wins over this field). true writes <config>.profile.html next to the config; a string sets the HTML report path.
    • [workspace] 6 Configuration block for the project workspace and folder structure.
      • Open the page of [workspace]
      • project_root = "." requiredPath to the project directory.
      • root = "../.." Explicit shared data workspace root.
      • data_dir = ‹path› Folder the input data are read from and downloads are cached in.
      • output_root = "outputs/run_a" Root directory for per-project outputs (.hmp/scratch/, share/).
      • catalog_path = ‹path› Explicit path to the project index database.
      • runs_dir = ‹path› Explicit path to the directory holding one sub-directory per run.
    • [geographic] 64 Configuration block for geographic and watershed delineation parameters.
      • Open the page of [geographic]
      • source_mode = "standard" Where the model domain comes from.
      • crs_project = ‹string› Target projected CRS for all outputs (e.g. 'EPSG:2154').
      • dem_correc_type = "fill" How the DEM is conditioned before the catchment is delineated.
      • terrain_engine = ‹string› Flow-routing engine that conditions the DEM and delineates the catchment.
      • domain_extent = "box" Selects the DEM surface used for the domain.
      • reuse_existing_outputs = false If true, reuse previously generated geographic artifacts when the cached fingerprint matches the current DEM, outlet/polygon and geographic settings.
      • reg_fold = ‹path› Folder with pre-computed regional flow rasters.
      • write_intermediates = false Keep intermediate rasters and shapefiles on disk after geographic preprocessing.
      • [geographic.catchment] 9 "dem" | "txt" | "from_outlet_coord" | "from_polyg_shp"How the model domain is defined.
        • Open the page of [geographic.catchment]
        • dem_init_path = "dem.tif" requiredPath to the DEM raster that is the model domain.
        • cell_size = "25 m" requiredmGrid cell size in metres used to rasterise the XYZ point cloud.
        • x_outlet = 352400.0 requiredmEasting of the watershed outlet in the projected CRS of the project, in metres.
        • y_outlet = 6788300.0 requiredmNorthing of the watershed outlet in the projected CRS of the project, in metres.
        • snap_dist = "150 m" requiredmMaximum snapping distance (metres) to move the outlet to the nearest stream cell.
        • buff_area = "10%" requiredMargin around the watershed polygon.
        • polyg_shp_path = "watershed.shp" requiredPath to the watershed polygon shapefile.
        • dem_resolution = "75 m" mCell size the DEM is aggregated to before anything is delineated, a length ('75 m', a bare number in metres).
        • catch_def = "dem" Catchment defined by the DEM raster extent.
      • [geographic.capped_breach] 2 Limits of the 'capped_breach' conditioning: max_depth (default 0.5 m) and max_distance (default 200 m).
        • Open the page of [geographic.capped_breach]
        • max_depth = 0.5 mLargest cumulative lowering, in metres, of one breach path (the 'max_cost' of Whitebox): the lowering summed over the cells of the path, not the depth of one cell.
        • max_distance = 200.0 mLongest breach path, in metres.
      • [geographic.synthetic] 16 Synthetic geographic support used when source_mode='synthetic'.
        • Open the page of [geographic.synthetic]
        • case_id = "flat20" Identifier used by local case runners and outputs.
        • [geographic.synthetic.grid] 8 Synthetic grid definition (extent and cell size).
          • Open the page of [geographic.synthetic.grid]
          • length_x = 100.0 mTotal domain length along x (metres).
          • length_y = 1.0 mTotal domain length along y (metres).
          • nx = 100 -Number of grid cells along x, over length_x.
          • ny = 1 -Number of grid cells along y, over length_y.
          • xmin = 0.0 Lower x coordinate of the support extent.
          • ymin = 0.0 Lower y coordinate of the support extent.
          • crs = "EPSG:2154" Projected CRS attached to synthetic outputs.
          • nodata = -9999.0 Nodata sentinel exported to raster artefacts.
        • [geographic.synthetic.topography] 7 "flat" | "linear" | "radial_island"Synthetic topography definition (shape, elevations, slope).
          • Open the page of [geographic.synthetic.topography]
          • kind = "flat" Analytical topography law: 'flat' keeps one constant elevation.
          • base_elevation = 20.0 mElevation of the flat ground surface, in metres.
          • right_to_left_amplitude = 0.0 Additional elevation reached on the left boundary relative to the right boundary.
          • island_radius = ‹number or "<n> m"› mCircular shoreline radius (metres).
          • crest_elevation = 10.0 Central island elevation (m).
          • center_x = ‹number or "<n> m"› mOptional x coordinate (metres) of the island center.
          • center_y = ‹number or "<n> m"› mOptional y coordinate (metres) of the island center.
      • [geographic.river_network] 9 Optional DEM-derived river-network extraction settings.
        • Open the page of [geographic.river_network]
        • enabled = false Enable DEM-based river-network extraction from flow accumulation during geographic preprocessing.
        • threshold_mode = "area_km2" Stream-initiation threshold selector.
        • threshold_area_km2 = ‹number› km2Contributing area threshold (km^2), required when threshold_mode='area_km2'.
        • threshold_cells = ‹number› -Number of upstream cells a cell must drain to start a stream.
        • prune_short_streams = false If true, remove short stream segments after extraction.
        • min_stream_length_m = 0.0 mMinimum stream length (metres) used by short-segment pruning.
        • compute_strahler_order = true Compute Strahler order raster from extracted streams.
        • compute_stream_links = true Compute stream-link identifier raster from extracted streams.
        • all_vertices = false Forwarded to Whitebox raster_streams_to_vector.
      • [geographic.enforce_lakes] 7 Optional lake hydro-enforcement of the routing DEM: carve the lake footprints so streams route into the lakes and drain to the outlet, without touching the model grid top.
        • Open the page of [geographic.enforce_lakes]
        • enabled = false Carve the lake footprints into the routing DEM before D8 so streams converge into the lakes and drain to the outlet through them.
        • lake_geometry_path = ‹path› Lake footprint polygons (gpkg/shp) to carve.
        • slope = 0.003 -Ramp gradient, in metres per metre of distance to the outlet.
        • buffer_m = 15.0 mBuffer (metres) applied to each lake footprint to bridge inter-lake sills and knit the shoreline into the carve.
        • capture_radius_m = 0.0 mIf > 0, run a SECOND delineation pass: any stream that dead-ends within this distance of a lake (a near-miss over a flat forebay) is carved to the lake and re-delineated, so its channel reaches the shoreline.
        • capture_max_streams = 8 Capture pass: cap on how many near-miss stream terminals are carved to lakes per pass (kept by decreasing flow accumulation).
        • capture_min_acc_fraction = 0.3 Capture pass: keep only near-miss terminals whose flow accumulation is at least this fraction of the largest, so a tiny rivulet is not carved.
      • [geographic.dam_carve] 4 Optional dam structure-carve of the ground: lower the dam footprint to the valley floor, for the routing chain and the model top alike, so a cutoff wall sits at the dam on a raw DEM.
        • Open the page of [geographic.dam_carve]
        • enabled = false Carve the dam footprint of the ground down to the local valley floor, so the routing chain and the model top both see the dam removed and the cutoff wall sits at the true dam on a raw DEM.
        • line_path = ‹path› Dam trace (gpkg/shp/csv) along which the ground is carved.
        • buffer_m = 40.0 mHalf-width (metres) of the carved corridor around the dam trace.
        • search_radius_m = ‹number or "<n> m"› mRadius (metres) of the neighborhood whose minimum elevation defines the valley floor the corridor is carved to.
      • [geographic.crossings] 7 Optional notch of the ground at the roads, railways and bridges that cross the generated channel tree: the embankment is lowered to the bed level read on both sides, and the catchment is delineated again on the notched ground.
        • Open the page of [geographic.crossings]
        • enabled = false Notch the ground at the crossings of the channel tree with the declared structures, then delineate again on the notched ground.
        • path = ‹path› Vector file of the structures, with the columns 'kind', 'source', 'name' and 'drop_m' of the crossings data variable.
        • kinds = ["road", "railway", "bridge"] Structure kinds to notch.
        • notch_width = 10.0 mWidth of the notch across the embankment, in metres.
        • bed_reach = 50.0 mDistance along the channel, on each side of the crossing, where the bed level is read, in metres.
        • max_depth = 3.0 mLargest lowering of any pixel, in metres.
        • snap_radius = 30.0 mA point structure (a bridge of the ROE) farther than this from the channel tree is ignored, and so is a channel pixel farther than this from its crossing, in metres.
      • [geographic.bed_regularization] 2 Optional least-change regularisation of the channel bed in the model top, on the pixels of the generated channel tree: the bed never rises downstream, crossing notches are gaps and declared weirs are drops.
        • Open the page of [geographic.bed_regularization]
        • enabled = false Regularise the channel bed of the model top: the least-change fit of the ground that never rises downstream along the channel tree, with the crossing notches as gaps and the declared weirs and dams as drops.
        • min_slope = 0.0001 -Minimum drop of the fitted bed per metre along the channel (m/m), given to the flats the fit pools.
    • [domain] 17 Domain configuration defining domain depth plus the spatial-support mode used for heterogeneous parameter mapping (none, geology, or zones).
      • Open the page of [domain]
      • zone_ids = [] Zone identifiers Domain.set_zone is allowed to register.
      • [domain.supports.<name>] 10 "generated_bands" | "generated_rings" | "catchment_zones" | "geology"
        • Open the page of [domain.supports.<name>]
        • kind = ‹"generated_bands" | "generated_rings" | "catchment_zones" | "geology"› requiredWhat the zones of this support are: bands along an axis, concentric rings, the catchment zones, or the geology units.
        • axis = "x" Axis the bands are cut along.
        • coordinate_mode = "relative" How the coordinates of this support are read: as shares of the domain from 0 to 1 ('relative'), or as lengths converted to metres ('absolute').
        • breaks = [] Ordered break coordinates delimiting consecutive bands.
        • labels = [] Ordered band labels.
        • radii = [] Ordered ring radii delimiting consecutive concentric zones.
        • source_zone_id = "catchment" Domain zone id providing the source catchment zonation.
        • default_cell_samples_per_axis = 8 Sub-sampling resolution per cell axis used when rasterizing band masks.
        • center_x = ‹number or "<n> m"› mOptional x coordinate of the ring center (projected metres).
        • center_y = ‹number or "<n> m"› mOptional y coordinate of the ring center (projected metres).
      • [domain.depth_model] 6 "constant_thickness" | "flat_substratum" | "raster_substratum" | "raster_thickness"Vertical domain model configuration.
        • Open the page of [domain.depth_model]
        • kind = "constant_thickness" Depth-model kind discriminator.
        • thickness = 50.0 mConstant aquifer thickness applied below topography (canonical metres).
        • substratum_elevation = 0.0 mFlat substratum elevation applied over the full domain (canonical metres).
        • offset = 0.0 mVertical shift added to the substratum everywhere (canonical metres).
        • min_thickness = 1.0 mSmallest aquifer thickness kept under the top (canonical metres).
        • scale = 1.0 -Factor applied to the thickness raster (dimensionless).
