[[export]]#

One export: what to write, when, in which format, where.

  • export [[array of tables]] · optional · 8 user keys, 2 dev or expert
  • Start a file: hmp config template --modules export (download it), then hmp config check file.toml. Minimal file

Repeat the table: one [[export]] block per item.

[[export]]
variables = "head"What to export: a name, a list of names, or "all" for everything the run holds. required example value
Path
export.variables
More

One namespace covers the mesh fields (head, watertable_depth, seepage_mask...), the series (discharge, discharge_obs...), the vector layers (watershed, hydrographic_network_reference...), the raster layers (watershed_dem...) and the table budget; 'hmp export <run> --list' prints what a run holds. A name no run can hold is refused before the solve.

Accepted
string or list of string
Example
"head", ["head", "discharge"], "all"
# time = ‹string or integer or list of string or integer›The instants to write: a date "YYYY-MM-DD", "first", "last", or a list of them.
Path
export.time
More

A date takes the stress period that holds it. A format that holds one instant (GeoTIFF, Shapefile, GeoPackage, VTU) writes one file per date. Left out, the whole simulation is written. Cannot be given with period.

Accepted
string or integer or list of string or integer
# period = ‹list of string›A window of the simulation, [start, end], two dates "YYYY-MM-DD".
Path
export.period
More

Every stress period it overlaps is written. Cannot be given with time.

Accepted
list of string
# format = ‹"netcdf" | "geotiff" | "csv" | "geopackage" | "shapefile" | "vtu" | "package" | "stac" | "rocrate" | "prov"›The file format.
Path
export.format
More

Left out, each data takes its natural format, or the one the extension of 'file' names. 'package' writes the portable .hmp archive of the run; 'stac', 'rocrate' and 'prov' write its metadata. Those four describe the whole run and take variables = "all" only.

Values
  • "netcdf" : A NetCDF file (.nc): fields and series over time.
  • "geotiff" : A GeoTIFF raster (.tif), one file per date.
  • "csv" : A CSV table (.csv): series and tables.
  • "geopackage" : A GeoPackage vector file (.gpkg), one file per date.
  • "shapefile" : An ESRI Shapefile (.shp), one file per date.
  • "vtu" : A VTK unstructured grid (.vtu) of the mesh, one file per date.
  • "package" : The portable .hmp archive of the run.
  • "stac" : The STAC metadata of the run.
  • "rocrate" : The RO-Crate metadata of the run.
  • "prov" : The PROV provenance record of the run.
Accepted
"netcdf" | "geotiff" | "csv" | "geopackage" | "shapefile" | "vtu" | "package" | "stac" | "rocrate" | "prov"
# folder = ‹path›The folder the files are written to, with automatic names.
Path
export.folder
More

A relative folder is read from the project's share/ directory. Defaults to share/<run>/.

Accepted
path
# file = ‹path›One exact file to write; its extension gives the format.
Path
export.file
More

A relative file is read from 'folder'. Only for a request that writes one file: several files need 'folder' and automatic names.

Accepted
path
# crs = ‹string›Output CRS, e.g. 'EPSG:4326'.
Path
export.crs
More

Rasters and vector layers are reprojected from the model CRS. NetCDF, VTU and CSV do not reproject and refuse it. Left out, the model CRS is kept.

Accepted
string
# resolution = ‹number›Pixel size of a GeoTIFF of a field, in units of the output CRS. CRS unit > 0
Path
export.resolution
More

Derived from the mesh when left out. Refused on a request that writes no raster.

Accepted
number
Valid range
> 0 (refused outside)
Unit
CRS unit
# layer = ‹integer›Model layer of a 3D field. >= 0 dev
Path
export.layer
More

Left out, every layer a format can hold.

Accepted
integer
Valid range
>= 0 (refused outside)
# nodata = -9999.0Fill value of the cells a raster has no data for. expert
Path
export.nodata
Accepted
number
