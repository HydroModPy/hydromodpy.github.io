Figures#

Every figure HydroModPy can draw, read from the figure registry of the code: what it reads, when it can be drawn, the options it takes with their type and default, and the class that draws it. Open a figure for its card. A preview image shows beside the name when one has been rendered for it.

To write a new figure, see Add a figure.

70 figures. A run draws the ones named in display.figures; display.overrides sets their options. hmp viz show <run> <name> draws one figure of a stored run.
