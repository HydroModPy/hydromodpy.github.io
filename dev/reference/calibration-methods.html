Calibration methods and metrics#

Every search method a calibration file can name, and every metric an objective block can score with. Both lists are read from the code at each build: the optimizer registry, the options model and the declared traits of each engine, the metric kernels and their formulas. Why the objective is built this way is in The inverse problem of a calibration.

Methods#

A file names a method with calibration.method, or per phase with calibration.phases.method. Left unset, the search gets the first method whose conditions it meets: hmp calibrate FILE --list-phases prints the choice and the reason, for each phase or for the one search of a file without phases. A name that is not registered is refused when the file loads, with the list of the names that are.

bisection#

A root search on one parameter: a coarse log sweep, then the bracket is halved.

It reads a signed residual, so every block it scores must use distance_gap, and the parameter must be searched in log space. It stops on the width of the bracket, never on the size of the residual. It is the method a search that names none gets when those conditions hold. Use it for the stream-network stage: one conductivity against a mapped network.

Options, written under calibration.method_options with method beside them, or in the method_options of a phase:

Option

Type

Default

What it sets

rel_tol

float

0.01

Relative width of the bracket at which the search stops, on the calibrated parameter. The paper’s one per cent. The criterion is never the size of the residual: it steps over zero and would never get small enough.

signed_component

str

"J_signed"

Name of the component carrying the signed residual whose sign the search brackets. Left at ‘J_signed’, a network output scored on two bounds is searched on J_signed_minimal and J_signed_maximal, one root each, and the value returned is their weighted geometric mean. Any other name is one root.

sweep_points

int

7

Points of the coarse log sweep run before the bisection. It checks the monotonicity the paper assumes instead of supposing it, sees every crossing, and produces the crossing curves for free. Zero gives the pure bisection of the paper.

bracket_expand

int

4

How many times the interval may be widened by one decade when no sign change is found. Beyond that the search raises rather than returning the better of the two ends.

  • Parameters: One, in log space only

  • Criterion: A signed one only: every block it scores reads a signed residual, distance_gap.

  • Stops: On a precision on the parameter: calibration.tolerance writes rel_tol, a relative precision on the parameter, passed through as is.

  • Budget: max_iter = "auto" counts the evaluations its rule needs before the first solve. A smaller number is refused or warned by hmp calibrate --check.

  • Parallel trials: Yes, with calibration.parallel.

  • Starts from an earlier phase: No.

  • Restarts: Refused by the multistart uncertainty: it returns the same answer every time.

  • Without a method: Chosen first, when the search meets every condition above.

cma_es#

Covariance matrix adaptation evolution strategy, from the cma package.

It needs the calibration extra. It can start from the value an earlier phase passed on. Use it on several parameters with a broad box and a cost with plateaus.

  • Restarts: Accepted by the multistart uncertainty.

da_mh_gp#

A delayed-acceptance Metropolis-Hastings chain with a Gaussian-process surrogate.

The surrogate screens each proposal and one run of the real model corrects the acceptance. It reads the cost as an RMSE, with the log-likelihood -0.5 * (cost / sigma_noise)**2, so score it on rmse. The best candidate is the mode of the chain. It needs scikit-learn, which the base install carries. Use it when you want a sample of plausible values rather than one optimum.

grid#

Every point of a regular grid, in the space each parameter is sampled in.

A log parameter gets a log axis. The grid is the same whatever the seed, so the search is a deterministic map of the cost. Use it on one or two parameters, for a first look at the cost or a reference to judge another method against.

  • Budget: max_iter = "auto" gives 100 evaluations.

  • Parallel trials: Yes, with calibration.parallel.

lhs#

One Latin hypercube design, drawn before any solve and evaluated whole.

Each stratum of each parameter is hit once. Use it for an even scan with a fixed budget on more parameters than a grid affords.

random_search#

Independent draws from the prior of each parameter.

It never decides it has converged, so it runs to its budget. Use it as a cheap baseline to judge another method against.

It takes no option.

  • Parameters: Any number

  • Stops: On its budget, or on a rule of its own options. calibration.tolerance is refused.

  • Budget: max_iter = "auto" gives 100 evaluations.

  • Parallel trials: Yes, with calibration.parallel.

  • Starts from an earlier phase: No.

  • Restarts: Accepted by the multistart uncertainty.

A population search over the whole box. It runs one trial at a time, so parallel buys nothing. Use it for a robust global search when trials cannot run side by side anyway.

scipy_nelder_mead#

A local simplex, scipy.optimize.minimize(method='Nelder-Mead').

It starts from the centre of the priors, or from the value an earlier phase passed on. It is the method a search that names none gets when its cost has no sign to bracket. Use it when the range is already narrow, or to refine the result of a coarse search.

Metrics#

An objective block names one metric with calibration.objective_blocks.metric. The search always minimises a cost: the Cost minimised column gives how the score of each metric enters it. In the formulas of a metric that reads a series, \(s_t\) is the simulated value and \(o_t\) the observed one at the same date, over the \(n\) dated pairs the scoring window keeps. A metric that reads a network defines its own terms under its formula.

distance_gap

Eq. 1 of the stream-network method: zero where the simulated network reaches as far as the mapped one.

\[\lvert D_{so} - D_{os} \rvert\]

where \(J = D_{so} - D_{os}\).

Lower is better; the search minimises it as it is.

D_so is the mean downslope distance from the simulated network to the mapped one, D_os the reverse. J is the signed residual a root search brackets. With two bounds, the cost sums the weighted gap of each bound.

distance_mean

Eq. 2 of the stream-network method: the mean mismatch of the two networks.

\[\tfrac{1}{2}\,(D_{so} + D_{os})\]

Lower is better; the search minimises it as it is.

A diagnostic, and a cost only to choose between structures already balanced by distance_gap. With two bounds, the cost sums the weighted mean of each bound.

kge

Correlation, variability and bias in one number.

\[1 - \sqrt{(r - 1)^2 + (\alpha - 1)^2 + (\beta - 1)^2}\]

where \(r = \mathrm{corr}(s, o),\quad \alpha = \sigma_s / \sigma_o,\quad \beta = \textstyle\sum_t s_t \big/ \sum_t o_t\).

Higher is better; the search minimises one minus the score.

mae

The typical miss, less driven by a few large ones.

\[\tfrac{1}{n}\sum_t \lvert s_t - o_t \rvert\]

Lower is better; the search minimises it as it is.

nse

The fit against a model that always predicts the observed mean.

\[1 - \dfrac{\sum_t (s_t - o_t)^2}{\sum_t (o_t - \bar{o})^2}\]

Higher is better; the search minimises one minus the score.

nse_delta

The fit of the change from one sample to the next, blind to the absolute level.

\[\mathrm{NSE}(\Delta s,\ \Delta o)\]

where \(\Delta x_t = x_{t+1} - x_t\).

Higher is better; the search minimises one minus the score.

Pair it with a metric on the level.

nse_log

The NSE of the logarithms: recessions and low flows weigh as much as the peaks.

\[\mathrm{NSE}\big(\ln(s + \varepsilon),\ \ln(o + \varepsilon)\big)\]

where \(\varepsilon = \max\big(10^{-9},\ 0.01\,\mathrm{median}\{o_t > 0\}\big)\).

Higher is better; the search minimises one minus the score.

Negative values are clipped to zero first, and the trial counts them.

nse_seasonal

The fit beyond the seasonal cycle of the observations. Below zero, the model does worse than that cycle alone.

\[1 - \dfrac{\sum_t (s_t - o_t)^2}{\sum_t (o_t - c_t)^2}\]

where \(c_t = a_0 + \textstyle\sum_{k=1}^{2} \big(a_k \cos\tfrac{2\pi k t}{P} + b_k \sin\tfrac{2\pi k t}{P}\big),\ \text{fitted to } o \text{ by least squares},\ P = 365.25\,\text{days} / \Delta t\).

Higher is better; the search minimises one minus the score.

P is one year counted in samples of the series, whose step Delta t is read from its dates. Two years are needed: a shorter series scores NaN. A series with no dates is taken as daily.

reservoir

Built for an impounded level: the seasonal half keeps the level honest, the increment half makes the water balance count.

\[\tfrac{1}{2}\,\mathrm{NSE}_{\mathrm{seasonal}}(s, o) + \tfrac{1}{2}\,\mathrm{NSE}(\Delta_{n} s,\ \Delta_{n} o)\]

where \(\Delta_{n} x_t = x_{t+n} - x_t,\ n = \max(1,\ \mathrm{round}(10\,\text{days} / \Delta t))\).

Higher is better; the search minimises one minus the score.

The seasonal half reads the dates as nse_seasonal does. The increments span ten days, or one sample on a coarser series.

rmse

Large misses weigh more than many small ones.

\[\sqrt{\tfrac{1}{n}\sum_t (s_t - o_t)^2}\]

Lower is better; the search minimises it as it is.
