Versions and stability#

This site documents version 2.0.0a5. It is a pre-release of the 2.0 line. Versions 2.0.0a1 to 2.0.0a5 are published on PyPI. What each one changed is in the changelog.

What a version number says#

HydroModPy follows Semantic Versioning. A pre-release adds a suffix that PEP 440 defines: a for alpha, b for beta and rc for release candidate, then a number, as in 2.0.0a5.

  • Major (X.0.0): a change that makes you edit your files. A removed or renamed TOML key, Python function or hmp verb, a new storage format, a different solver behaviour.

  • Minor (X.Y.0): a compatible addition. A new solver, a new optional key with a default, a new verb or function.

  • Patch (X.Y.Z): a bug fix only. No new public name, no change you have to adapt to.

A removed name is not kept as an alias. If a change needs you to edit a file, it is a major change, unless it lands in a pre-release before the stable version.

Install a version#

pip skips pre-releases unless you ask for them. To follow the 2.0 line, or to pin an exact release so a project reads the same keys tomorrow, such as 2.0.0a5 now:

pip install --pre hydromodpy
pip install hydromodpy==<version>

A project written for version 1 stays on the tag v1.0.0 of the repository. Version 1 is frozen on the v1.0 branch. It gets no new work.
