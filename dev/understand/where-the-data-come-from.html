Where the data come from#

A result is only as good as its inputs. This page names the data that HydroModPy can read, who produces them, how fine they are, and what to do about their licences. It is written for a reader who must judge a result, not for one who must download data: the keys that declare the data are in [data].

Fineness matters#

Each input has its own scale, and the model cannot be finer than the inputs that control a result.

  • The rain comes on an 8 km grid. The catchment of example 04 is 64.6 km², so a few grid points cover it. In example 04, one monthly recharge series serves the whole catchment: no difference between two hillsides.

  • The relief sets where water leaves the ground, and the cell of the model is 75 m. A map is read at the scale of the hillside (resolution).

  • A geological map at 1:50,000 draws zones that are hundreds of metres wide. It does not tell the conductivity of a particular field.

  • A mapped stream network draws what someone chose to draw, with a positional error. The score of a network takes it into account only if that error is declared (Scoring a simulated stream network).

Licences#

Public data do not all carry the same licence. The licence of each source, when the code knows it, is listed on the generated page Data sources. Where the code does not know it, the page says so. It does not guess.

Three rules follow from the way the code records licences.

  • A file you provide has the licence you declare. The model cannot know the licence of your file. You state it in a small companion file next to the data.

  • A result inherits from its inputs. A run states the combined licence of what it read, and writes it into the attributes of its field files and the footers of its tables. If one input has no known licence, the run states undetermined. A run cannot promise more than its least known input allows.

  • Undetermined is not forbidden. It means that nobody recorded the terms. Read the terms of the producer before you reuse or redistribute a result.

This page is not legal advice. Cite the producer of the data that a result relies on.

Can I check which data were used?#

Yes. Each run lists its input files with their checksums, and the project can pin the whole data cache. See Can I check what was run?.
