[flow.sinks_sources.flow_barriers]#

Typed payload for one MODFLOW 6 horizontal flow barrier (HFB).

  • flow.sinks_sources.flow_barriers { name = table } · optional · 13 user keys

One table per name you choose: [flow.sinks_sources.flow_barriers.<name>]. The name is free text.

[flow.sinks_sources.flow_barriers.<name>]
# enabled = trueWhether this barrier is built. experimental

# crest_elevation = ‹number›Absolute TOP elevation of the barrier [m, model datum]; defaults to the cell top (the DEM). m experimental
Path
flow.sinks_sources.flow_barriers.<name>.crest_elevation
More

Set it when the barrier crest sits below the DEM top. Not calibratable: raising the crest and lowering hydchr both shrink the flow section the wall lets through, so a search cannot tell the two apart. It is a built structure, not a fitted number; path = in [calibration.parameters] still reaches it for whoever wants to override this deliberately.

Accepted
number
Unit
m
# base_elevation = ‹number›Absolute BOTTOM elevation of the barrier [m, model datum]. m experimental
Path
flow.sinks_sources.flow_barriers.<name>.base_elevation
More

When set, the HFB spans [base_elevation, crest_elevation or top] and blocks EVERY layer in that band. Use it to make a full-height dam impervious: the concrete body plus the grout curtain block all flow from the crest down to the curtain foot (e.g. base_elevation = 41 m), so nothing seeps across the dam above that. Mutually exclusive with depths. Not calibratable: a deeper foot and a lower hydchr produce the same reduction of under-dam flow, so putting both in a search is equifinality by construction, the same mechanism that makes the second stage of the stream-network protocol pin the specific yield on its bound. When the foot is genuinely unknown, run mode = "comparison", one elevation per run, which also yields a defensible sensitivity instead of a fitted number; path = in [calibration.parameters] still reaches it for an override.

Accepted
number
Unit
m
# hydchr = ‹number›HFB hydraulic characteristic [1/T] = K_barrier / thickness_barrier. >= 0 calibrable · log experimental
Path
flow.sinks_sources.flow_barriers.<name>.hydchr
More

A near-zero value (e.g. 1e-9 1/s) is a quasi-impermeable wall. Zero is accepted only without XT3D: MODFLOW 6 ignores a zero hydchr under XT3D, so the build refuses it with XT3D active (XT3D turns itself on for triangle and strongly non-orthogonal meshes). Each face of the barrier receives hydchr times trace length over the summed face length, so a zigzag chain of faces keeps the declared conductance. Mutually exclusive with k + thickness.
