More

The zone is the set of pixels where the field is below the value of below, or above the value of above. Give path or where, not both.

Values
  • "height_above_stream" : Height in metres of the ground above the stream it drains to, computed from the DEM and the river network traced from it ([geographic.river_network]). The mapped network never enters. Takes below.
  • "watertable_depth" : Depth in metres of the water table below the ground in the run named by run, at any of its time steps: its minimum over time is compared to below, its maximum to above.
  • "seepage" : Drain outflow per cell area, in mm/d, in the run named by run, at any of its time steps: its maximum over time is compared to above, its minimum to below.
Accepted

"height_above_stream", "watertable_depth", "seepage"

[mesh.voronoi]
# seeds = ‹"generated" | "triangulation"›Where the generators of the Voronoi cells come from. dev
Path
mesh.voronoi.seeds
More

Unset, they are the vertices of the triangulation read from [mesh.triangle] path when a path is given, and generated by the engine otherwise.

Values
  • "generated" : The engine places the generators itself: along the rivers, in mirror pairs on the face lines, on the boundary, and freely from the size field.
  • "triangulation" : The vertices of the triangulation read from [mesh.triangle] path are the generators.
Accepted
"generated" | "triangulation"
