Architecture gates#

Built from the module docstrings of tests/unit/architecture/test_*.py and the YAML contracts beside them each time the site is built. Fix a wrong row there.

10 gate modules and 7 YAML contracts. Run them all with pytest tests/unit/architecture -q. The rule is the first paragraph of the module docstring; the checks are its test functions.
