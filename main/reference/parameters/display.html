[display]
# enabled = trueMaster switch.
Path
display.enabled
More

When False, no figure is rendered or saved.

Accepted
true | false
# theme = "default"Named theme applied before rendering any figure: default, print or dark.
Path

Accepted
string
# on_error = "warn"Behaviour when a figure that IS applicable fails while rendering.
Path
display.on_error
More

'warn' logs and continues (default, keeps a long run alive); 'raise' propagates, which is what example and CI configs want so a broken figure cannot pass unnoticed.

Values
  • "warn"
  • "raise"
Accepted
"warn" | "raise"

integer
Default by edition
150 with edition 2.0, 300 with edition 2.0
Valid range
>= 1 (refused outside)
