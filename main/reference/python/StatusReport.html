class StatusReport(project_root, plan_hash, plan_stale, rows=<factory>)[source]#

The status of every case of the current plan.

counts()[source]#

Return the number of cases per status, in the order of the rows.

to_dict()[source]#

Return the report as JSON: plan_hash, plan_stale, counts and cases.

Each case holds the CASE_COLUMNS as text, with an empty string for a value that is not there and a date to the second. This is the document hmp ls --plan --format json prints.
